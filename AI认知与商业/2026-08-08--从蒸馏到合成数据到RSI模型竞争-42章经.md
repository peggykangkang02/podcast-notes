# 模型自己训自己的时代，创业公司的活路在哪

平台：小宇宙｜时长约 59 分钟｜播放 14133

## 知识概览

这期请来 Evolvent AI 联创孟繁青，一个还在读博就出来创业的 post-training 一线研究员，上一份实习就在头部模型厂参与多个重要模型的发布。主持人把模型竞争拆成几个最热的谜面来聊：预训练和后训练谁更值钱，国内模型到底靠什么追赶海外，蒸馏算不算核心竞争力，以及合成数据卖到几千块一条背后是什么行情。

最有信息量的是他给出一整套反直觉的判断。训模型的工程门槛已经大幅降低，模型厂内部早就把训练做成了提交数据就能远程跑完的服务，研究员真正的手艺活只剩造数据这一件事。而造数据没法预先判断好坏，量化指标只能做初筛，最终必须训了才知道结果。数据行业本身也变化极快，普通 agent 轨迹数据已经接近尾声，能在里面活下来的公司必须有一线亲手训模型的人。

节目后半程的重头戏是 RSI，也就是让模型自己迭代自己。他抛出一个很锋利的观点：不存在 RSI 基础模型这回事，world model 和 value model 早在预训练阶段就内化进了模型，所谓 RSI 方法本质上是一个更聪明的深度优先搜索，只是把回溯判断从代码换成了大模型。所以创业公司的机会不在训一个会自我进化的模型，而在模型厂和应用层之间的那条 RSI 通道。

对想理解 AI 竞争结构的人来说，这期难得地把算法、数据、基础设施、组织架构四层串在一起讲，最后还给蒸馏称了重：它是加速手段，不是决定性因素，国内模型变强的根基在预训练阶段被资源倒逼出来的架构创新。

**适合谁听：**
- 关注国内大模型竞争格局的人，能拿到一张看清各家用什么筹码竞争的地图。
- 做 AI 应用或数据生意的创业者，能摸清合成数据、蒸馏的真实行情和行业拐点。
- 想判断模型自进化是叙事还是真命题的人，能听到一线研究者对 RSI 的技术拆解。
- 想进入 AI 行业的学生和从业者，能对照自身判断该练工程能力还是学术能力。
- **可以跳过**：不关心模型训练技术细节的话，前二十分钟关于 post-training 环境与造数据流程的描述可以略过，直接从国内模型竞争的部分听起。

## 重要观点

**1. 训模型的门槛已经低到只剩造数据**
模型厂把训练生态做成了内部服务，研究员提交一份数据、远程发一个请求就能完成一轮 SFT。对多数普通算法研究员来说，训练本身不再是壁垒，真正的分水岭回到数据上：同样的数据不同人做出来效果完全不同，背后是大量靠手感、靠踩坑攒出来的 know-how。

小白视角解读：以前以为训练模型是拼谁家工程师更懂底层，现在更像拼谁手里的题目和答案质量更高。普通人该转变的思路是，AI 领域能靠手艺吃饭的位置正在往数据上游移动，别再纠结怎么训模型，该琢磨怎么提供模型自己学不到的好数据。

**2. 数据质量没法提前判断，只有训了才知道**
衡量合成数据，主要看轨迹里有没有作弊、题目难度是否适中，但这些指标只能做初筛。真正能不能涨点，必须拿去训练跑一遍，结果不好就推翻重来，本质是一个偏黑箱的试错过程。

小白视角解读：数据生意会像手工作坊，每个环节都靠试错。普通人听到 AI 数据别以为是个标准化行业，它更像做菜，菜谱写得再好也得客人尝了才算数。想入局就要接受高试错成本，而不是找一套保证有效的模板。

**3. 国内模型的追赶靠预训练架构创新，后训练反而是短板**
普遍印象是国内人多工程强，后训练应该占优，嘉宾的判断正好相反。国外模型厂在数据上的积淀比国内早约半年，后训练本质拼数据积淀和组织能力，国内反而弱，所以才会大量用蒸馏去补数据短板。真正缩小差距的主力，是预训练阶段用更少算力逼出来的架构创新。

小白视角解读：大家以为落后的地方，架构和算法，其实是国内最争气的地方；以为占优的地方，工程和数据，反而是追赶的难点。这种反直觉提醒我们，看一个团队别只盯表面资源，要看它被约束逼出了什么别人没有的能力。

**4. 模型竞争不会一家独大，只会交替领先**
开源社区让技术路径在很短时间内形成共识并扩散，某家发一个大版本会在榜单上领先几个月，随后被另一家超越。长期的胜负手未必是卡，而是组织架构：多模态要不要单独成队，研究力量怎么划分，这些直接决定一家公司整体跑得比对手快还是慢。

小白视角解读：别迷信某某模型永远最强，技术优势是流动的。对用户和创业者的含义是，押注单一模型风险极高，架构上要能随时切换底座模型，让组织自己的迭代速度成为真壁垒。

**5. 不存在 RSI 基础模型，只有更聪明的 DFS**
所谓自我进化，形式上是给模型一个环境和目标，让它持续操作、拿到反馈、修改自己。技术内核其实是一个由大模型承担剪枝和回溯判断的深度优先搜索，预训练已经把 world model 和 value model 内化进去了。RSI 变强只取决于知识内化质量和上下文窗口长度，所以没有专门的 RSI 基础模型，模型厂自己就在训同一个东西。

小白视角解读：别把 AI 自己进化想象成一个全新物种从石头里蹦出来，它更像给一个已经很聪明的人配上纸笔和镜子，让他反复检查自己的草稿。普通人判断任何 AI 能力，都别被营销名词带走，要看底层是不是还是那套搜索加反馈的老逻辑。

**6. 合成数据是数据业的第三代，而且可能已过中后期**
数据行业经历了普通人标数据、专家出题标注、合成数据三代演进。普通 agent 轨迹数据已经接近尾声，价格也在分化：一条高质量合成长任务能卖几千块，真人轨迹只能按量走。数据公司要活下去，必须养着能亲手训模型的一线研究员。

小白视角解读：卖数据也是快速迭代的行业，去年赚钱的姿势今年可能就失效。普通人别因为听说合成数据火就冲进去，门槛正在快速抬高，下一波 RSI 数据的产生需要跑十几小时甚至一天的训练轨迹，只有干过脏活累活的人才跟得上。

**7. 蒸馏是加速手段，不是国内模型的命根子**
即便把蒸馏的门路全部封死，国内模型也能靠预训练架构创新和自己的合成数据追赶，只是更费劲一点。被反复指责的蒸馏本质上是个捷径工具，走捷径可能让人遗失主路上的 insight，这也是有头部公司选择不蒸馏的顾虑所在。

小白视角解读：别被蒸馏等于偷窃的舆论带跑，它只是一种训练加速技巧。普通人的收获是，捷径分两种用法：用来补短板是策略，用来替代基本功就是慢性自杀。做产品也一样，可以借鉴别人的好做法，但必须保住自己亲手探索出来的能力。

## 信息差

**1. 训练模型这件事，普通研究员已经被降级成纯做数据的人**
大多数外人以为模型研究员每天在调算法、改架构，实际上模型厂内部早把训练做成了服务，提交数据就能远程跑完整个流程。算法的演进规律是越来越简单、越来越直接面向结果，后训练最终收敛到把数据做好这一件事。

小白视角解读：外界看 AI 人才都在搞高大上的算法，真实图景是核心稀缺能力悄悄变成了造数据。大多数人想错的地方在于高估了训练的技术含量，低估了数据的含金量。该信的是，离结果最近的环节才有议价权。

**2. 一条合成数据可以卖到几千块，贵的按条算**
合成数据里最贵的不是量而是单条质量，一条超长任务轨迹能卖几千元，专家做题数据一两千，真人交互轨迹只能批发走量。原因是长轨迹本身的产生就很难，有的要跑十几个小时甚至一天，只有真正懂模型训练的人才做得出来。

小白视角解读：数据不是参与的人越多越值钱，而是越难产生越值钱。大多数人的直觉是数据生意拼规模，真相是拼别人造不出来。这给普通人一个判断标准：任何生意里，能被规模化复制的部分都会迅速贬值，稀缺永远藏在难造的部分。

**3. 最领先的模型，用自己的轨迹训自己也能变强**
通常以为合成数据是落后模型抄领先模型作业用的，但嘉宾指出，只要环境足够复杂、题目和评分体系足够高质量，哪怕模型拿自己探索出的正确轨迹来训练自己，也能持续提升。这正是 RSI 成立的技术前提。

小白视角解读：大多数人以为自己教自己没有新增信息，不可能进步，真相是高质量反馈循环本身就构成进步。这像运动员反复看自己的比赛录像改动作。对普通人的启发是，自我迭代不是原地打转，前提是你能给自己造出足够真实、足够难的考题。

**4. 模型厂疯狂秀 AI4S，是因为 coding 已经秀不动了**
coding 是衡量模型智力的基础赛道，但它的训练流水线已经趋于稳定，增长还在却缺少新叙事。于是模型厂转向用科学发现、数学猜想这类更能检验智力上限的场景做发布，叙事从奥赛升级到诺贝尔。

小白视角解读：别以为模型厂做科学是突然想造福人类，那也是一种竞争营销，为了证明智力上限。普通人看 AI 新闻要多问一句，他为什么此刻展示这个，很多动作不是技术驱动，而是叙事驱动。

**5. 普通用户早已无法体感模型的代际差距**
随着模型一次次发版，对普通用户来说它们之间的强度差别已经很难感知，只能靠越来越脱离日常使用的榜单来区分。对垂直场景更是如此，根本不需要最强的模型，一个小模型配简单工作流就能满足需求，成本更低速度更快。

小白视角解读：大多数人追着最强模型跑，其实手里的活儿用开源小模型就够。真相是模型能力的边际感知在钝化，普通人该把注意力从用哪个最强模型，转向哪个组合够用且便宜，省下的钱和精力才是竞争力。

## 章节纪要

**开场与嘉宾背景**
- 嘉宾孟繁青自我介绍：NUS 博士生、Evolvent AI 联创，此前在头部模型厂实习做 agent 与模型基础设施，参与过多个重要模型版本发布。
- 他自嘲属于典型的新画像：年轻、PhD 在读就创业、post-training 出身。

**预训练与后训练创业的差异**
- 预训练人才难创业，因为每天打交道的是数据趋于饱和前提下的架构和优化器，极度吃资源，初创公司覆盖不了成本。
- post-training 天然离落地更近，创业更多，核心就两块：造数据和做平台。

**Benchmark 从做题变成模拟工作环境**
- 旧 bench 像给模型出数学题，只测大脑；新 bench 搭出模拟白领工作软件的完整环境，让 agent 边思考边动手。
- 评判变复杂：要验证模拟环境与真实环境在同样输入下输出一致，检查被拆成大量细粒度得分点，仍依赖人的精细设计，由人和 AI 一起打分。

**训练被做成服务，造数据成为核心手艺**
- 模型厂内部把 SFT 生态做成服务，研究员只要交数据，就能远程跑完训练全流程，训练门槛大幅下降。
- 造数据并不枯燥：agent 目前只能做机械化修正，提不出造数据的 insight，模型厂研究员的数据 know-how 仍是核心资产。
- 数据质量的量化维度：能否在不作弊前提下刷高 benchmark，以及是否在写作等偏文科任务上有性能回退。
- 数据好坏难以预测，量化指标只能初筛，最终要训了才知道。

**国内模型竞争格局**
- 国内算力约为国外十分之一，却逼近国外水平，靠资源倒逼出的预训练架构创新，比如各种省计算量的注意力设计。
- 后训练反而是短板：数据积淀晚约半年，因此大量靠蒸馏补短板。
- 模型竞争是交替领先，不存在某家长期独大；组织架构调整能带来突飞猛进，多模态是否单独成队这类划分直接影响迭代速度。

**什么是 RSI 与 self-evolving**
- 形式化定义：给模型一个工作环境和目标，让它持续操作、拿反馈、自我修改，直到突破上限。
- 分层理解：最表层是输出前自查迭代，中间是 harness 让 agent 自我运转，最深层是模型自己训练出更强的模型。
- 没有 RSI 基础模型：world model 和 value model 在预训练时已内化，RSI 变强靠知识内化质量和上下文窗口长度。
- RSI 方法本质是更聪明的 DFS，回溯判断交给大模型，配合剪枝把精力集中到最有希望的分支。

**harness 与模型厂、应用层的分工**
- 模型会和自己配套的 harness 一起发版，后训练反传让两者互相适配，harness 会变简单但不会消失。
- 通用领域如 coding 无需第三方 harness；垂直领域可用开源小模型配简单工作流，仍有第三方生存空间。

**合成数据、真人数据与蒸馏的行情**
- 数据演进三代：普通人标数据、专家标注、合成数据，当前可能已到合成数据的中后期。
- 普通 agent 轨迹数据接近尾声；专家数据需求下降，因为对专家的要求从做题升级到出题且不与他人重合。
- 价格参照：超长合成任务单条数千元，专家数据一两千，真人操控轨迹按量批发。
- 蒸馏分硬蒸和讲究技巧的软蒸；环境与评分体系足够高质量时产出的是好数据，对落后模型价值最大，对领先模型同样有用。
- 模型厂外购合成数据，是为了冲淡自有数据的分布偏差。

**算法、数据、infra 的关系**
- 嘉宾认同算法就是数据、数据就是 infra、infra 就是算法：算法收敛到统一形式后拼的是数据，长轨迹训练需要 infra 做并行优化，infra 和算法都跟着数据需求演进。
- 数据量未来会增加而非枯竭：agent 合成数据是新来源，用得越多越能反哺出更好的合成数据。

**模型厂现状与 AI4S 新叙事**
- coding 仍是主线，流水线稳定但叙事变少，模型厂转向 AI4S 等新路线作为展示模型智力的手段。
- 模型增速仍在，但高薪与海量资源投入能否长期维持，是另一回事。

**蒸馏的真实分量与收尾**
- 蒸馏不是国内变强的决定性因素，预训练架构创新是根基，蒸馏只是加速手段，封死也不致命。
- 不蒸馏公司的顾虑：捷径会让人遗失主路上的 insight。
- Evolvent AI 跑半年，团队以年轻研究员为主，一块做核心数据与商单，长期做 RSI，定位是桥接模型厂与应用层的中间层，已发布面向数据的 RSI benchmark。
- 招人公开说不看论文引用，更看重工程能力。

## 思考

**当训练变成提交表单，壁垒就转移到了没人看见的地方**
整期最有冲击力的不是哪个模型又变强了，而是训练这件事在内部已经被拆成交数据、跑服务、拿结果的流水线。这说明一个规律：一旦某个环节被工程化，它的稀缺性立刻蒸发，所有溢价都会逃往下一个还没被工程化的环节。我见过太多人挤在已经被做成服务的地方比拼努力，却对真正的稀缺视而不见。可迁移的判断是，每当一个能力开始变得提交即可运行，就说明它的红利期正在结束，该去找下一个仍处于手工作坊阶段的环节了。对个体也一样，当你的岗位能被写进内部流程，你的价值就得靠流程外的东西重新证明。

**评判不了的东西，才是别人赚你钱的地方**
造数据的人最诚实的一句话是，数据好不好最终训了才知道，一切指标只能初筛。任何行业只要存在只能靠结果倒推的环节，这个环节就有极高的信息不对称，也就握有定价权。反过来，一个东西如果能被清晰量化打分，它就会迅速变成货架商品被压价。普通人买任何方法论之前都可以先问一句，这套东西的评判标准是前置还是后置，凡是后置才能验证的，贵有贵的道理，便宜则大概率是假的。

**资源少不是劣势，而是逼出独特能力的压力容器**
国内模型用十分之一的算力追平大半程，靠的是省计算量的架构创新，不是堆卡。这打破了我过去资源多就赢的线性直觉。真实规律是，约束条件会逼人选择一条不一样的路径，而那条路径反而可能成为后来的壁垒。对出海小团队尤其成立，你比不过大厂的预算，但你所背靠的约束会逼你长出大厂没有的生存形态。关键是别把资源少当借口，而是把稀缺当成设计约束来解题，缺什么反而可能决定你长成什么样。

**别押注单一模型，把底座做成可替换的**
嘉宾对格局的判断是交替领先，技术路径会在开源社区快速扩散成共识，没有谁能靠独门优势长期称王。对做应用的人，这既残酷又让人安心。残酷在于不存在一劳永逸的技术护城河；安心在于，你也不用担心押错某个底座万劫不复。所有 AI 产品都该默认模型会被替换，把提示词、工具调用、数据回流做成可移植层，让换模型像换零件而不是换整台机器。把赌注从具体模型挪到接口和数据资产上，才是对抗底座波动唯一稳赚的投资。

**自我进化不是玄学，是给聪明人配了纸笔和镜子**
把 RSI 翻译成更聪明的深度优先搜索，一下子把 AI 自己迭代自己从科幻拉回工程。搜索算法几十年前就有，新增的变量只是回溯判断的执行者从代码换成了大模型。这个拆解最大的认知增量在于：所谓智能跃迁很少是发明全新机制，更多是给已有的老机制换一个更聪明的执行者。看任何热词都该先拆这一层，它复用了什么旧机制，新执行者带来了什么增量，能这样拆，就不会被任何新名词唬住。

**能走捷径时故意不走，是在花钱买主路上的洞察**
蒸馏明明能加速，却有人坚持不蒸馏，理由是捷径会让你遗失主路上的 insight。这句话扎到我了，因为现实里几乎所有人都在追求最短路径，却没人计算过绕路的机会收益。走捷径省下的是时间，付出的是对底层逻辑的感知，而后者恰恰是判断力稀缺的来源。一个人愿意在什么环节放弃捷径，基本暴露了他真正看重什么，这是比任何表态都诚实的信号。把这句话用回自己身上，值得问的从来不是这件事有没有近路，而是近路会让我错过什么必须亲身体会才知道的东西。

**够用且便宜的小模型，正在吞掉大量最强模型的需求**
普通用户已经很难体感模型代际差距，垂直场景用开源小模型配简单工作流就够。这说明模型能力整体正在越过大量真实需求的门槛线，市场结构从选最强转向选够用。对出海从业者这是明确的成本信号：别再为用不上的算力付溢价，也别迷信必须追最新旗舰。把省下的钱投到数据、反馈循环和交付质量上，回报会高得多。真正的稀缺正在从模型本身，转移到谁更懂场景、谁手里握着别人没有的数据。

**靠试错养出来的手感，是比学历和论文更硬的通货**
嘉宾招人说不看论文引用，只看工程能力，因为高质量训练轨迹必须亲手训过模型才造得出来。这背后是条通用规律：在高试错成本的领域，书本和论文能传递的知识会快速贬值，只有亲手蹚过坑攒下的手感才有定价权。对想进 AI 行业的人，与其刷论文，不如亲手把一个模型从数据做到发版；对任何行业都一样，简历上真正值钱的不是你学过什么，而是你亲手用错误喂出来过什么。
