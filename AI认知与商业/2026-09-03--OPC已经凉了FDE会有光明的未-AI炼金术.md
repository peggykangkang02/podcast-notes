# FDE 只是 AI 渗透企业的过渡工具，真正的机会在可塑性软件

平台：喜马拉雅｜时长约 66 分钟

## 知识概览

这期表面是主播们把一周的行业新闻摊开来聊，从 OPC 降温、FDE 升温，到国产模型集体发布，再到 DeepSeek harness 的争议。但串起来看，三条主线其实都在给同一件事算命：在 AI 时代，靠 AI 卖人、卖能力、卖软件的生意，到底怎么收钱、能收多久。两位主播一个刚一个人闷头写了快一个月自家新一代 agent，一个在跑 AI 原生组织转型还准备去混沌讲课，所以每个话题都贴着地皮落，聊的是“这玩意儿到底能不能闭环”。

前半程的核心判断很锋利：OPC 不成立，因为大部分人卡在“把活变成钱”而不是“能不能干活”；FDE 和外包没区别，它只是 AI 让研发成本趋零后，用贵的人做便宜交付的产物，而且作为过渡职能，它会随着企业把 AI 缝隙填满而慢慢消亡。真正支撑 FDE 生意的时代红利，是信息差大到荒诞，企业家连装 codex、绑信用卡都要人上门教，这种“你觉得匪夷所思的笨”背后全是机会。

后半程信息密度更高，主播用真实使用体验说话：国产一线模型在八成日常开发任务上已经和顶级模型无差别，但长程大任务还是只有 Anthropic 扛得住；蒸馏是高 ROI 又合法的常规操作，字节、谷歌没出 SOTA 未必是没蒸馏。接着从 DeepSeek harness 的“怪异”聊到可塑性软件，判断人人都在做的三栏式 agent 客户端是走歪了，下一步是把 agent 能力插进企业已经有的 ERP 和流程里，让软件从买来定型变成按人定制。

最后收在两个具体的念头上：一个想去洛阳、开封、长沙这些二线城市看看 AI 的真实普及度，相信 AI 该服务十二亿人而不是一千万人；一个演示了用几百块硬件加一台老电脑攒出自己的语音管家。对想入局 AI 的人，这期不喂结论，给的是怎么识别概念和生意、怎么判断 agent 产品往哪长、组织 AI 化该从哪下手的判断框架。

**适合谁听：**
- AI 从业者、独立开发者：拿走“别做 OPC、先卖再攒”的纪律，以及产品必须有自己的取舍和立场
- SaaS 与出海创业者：拿走“人人做三栏式 agent 客户端是死路，可塑性软件和注入遗留系统才是下一步”的市场判断
- 传统企业管理者、咨询顾问：看到真实的落地信息差、内部转型的“借刀杀人”政治，以及用 AI 顶替组织职能的实操样本
- 自媒体新手：理解“AI 乘自媒体”是当下副业供需两头都旺的切口，内容生产的工具也在变成可改造对象
- **可以跳过**：中段对七八个国产模型逐个打分和吐槽速度的部分可整段跳过，实测结论已浓缩进重要观点；片头聊播客设备升级、片尾聊视频化的部分属于闲聊

## 重要观点

**1. OPC 不成立，小团队才成立，卡点永远在“把活变成钱”**
一个人能干活，个体户早就能干活了，这不稀奇。稀奇的是大部分离开公司的人从没在市场上直接卖过东西，卖外包、卖课、卖咨询都算，他们没经过“把劳动变成钱”这一关的训练。所以会不停逃避现实，不停做东西，用熟悉的劳动躲开陌生的交易。而且现实世界摩擦很多，光为收钱，合同、对公流程、催款就能耗掉半个人。
小白视角解读：别被“一个人就是一家公司”的口号带走，它只回答了前半题“一个人能干很多活”，没回答更难的后半题“谁能持续给你付钱”。普通人该做的不是闭门攒能力，而是先开卖，让真实的收款反馈倒逼你压缩价值、打磨产品。

**2. FDE 和外包没有区别，这个词已经被用烂了**
早期 FDE 确实有区别，是用咨询公司那种六十万美金的人去干六万美金外包的活，贵的人能边干边帮你理业务，再把方法论沉淀回总部。过去咨询完往往还要花十个月写代码，所以才有埃森哲这类把交付一并吃掉的 IT 咨询。今天 AI 把研发成本打到趋近于零，一个人聊完需求对着 coding agent 口喷一通就交付了，显得既能仰望星空又能落地。但如今谁都能管自己叫 FDE，它跟外包已经没有差别。
小白视角解读：FDE 火不是因为交付变高级了，而是因为“贵的人现在也能便宜交付”。普通人要分清自己卖的是人天还是可复制的资产，卖人天永远会被人比价，只有把经验沉淀成可复制的东西才有定价权。

**3. FDE 是过渡职能，会随着企业渗透 AI 的过程慢慢消亡**
FDE 的价值是填补“企业渗透 AI 的缝隙”。企业要解决的从来不是 AI 效率问题，而是业务问题，餐馆得有客人来吃饭，零售得有订单。随着模型变强、产品变完善，这些缝隙会被内部员工拿着 agent 自己填上，FDE 的职能就完成了历史任务，该移交能力然后去下一家。
小白视角解读：填补过渡期的生意需求真实但窗口有限。能持续下去的，是把过渡经验沉淀成可规模化的产品，比如批量帮公司培养内部 FDE、做 AI 时代的埃森哲，而不是永远把自己当一块到处堵漏的胶水。

**4. 内部转型推不动，多数是位置问题，不是能力问题**
真转型成功的公司，老板够狠又能下场管业务。但大多数老板虽然能把下属喷得像狗，却已经干涉不了业务，也不敢动真正管业务的高管。高管抵触 AI，不是因为他不懂，而是转型对他没好处，要削他的权、减他的人。这时候请外部的咨询或 FDE，本质是借刀杀人，老板需要一个不用脏自己手的外部力量来推进内部改革。
小白视角解读：如果你在组织里推 AI 推不动，先别怪大家笨，先画一张受益者和受损者的图。作为外部服务者更要明白，你真正的客户不是公司这个 logo，而是那个需要借你这把刀的具体的人，想清楚他的利益，生意才谈得拢。

**5. 国产一线模型在八成日常开发任务上已无差别，长程大任务只有 Anthropic 扛得住**
主播重度用了好几家新模型，结论是给一个明确具体的代码任务，已经分不出和 GPT、Claude 的明显差别，内部 harness 拿去走 code review、修 bug、上线也没问题。但真正长程、复杂、大上下文的任务，所有模型目前都做不过 Anthropic。另外快本身就是能力，现在大家都并行开很多窗口，模型再强，慢到让人等就没人用。
小白视角解读：给 AI 挑工具别只看榜单分数，先给任务分类。日常任务谁便宜、谁快就用谁，长程硬骨头再上顶级模型。对普通人和小团队，这意味着你根本不必为最贵的智能买单，贵的那部分溢价只在极少数场景成立。

**6. 蒸馏是高 ROI 的常规操作，既不违法也不违道德**
蒸馏本质是自动获取更好模型的训练样本，只要有足够多的账号和钱就能横向扩展，而人工写训练数据又慢又不可横向扩展，两者效率差就是让 AI 写代码和让人写代码的差别，ROI 极高。买了 API 怎么用是用户的自由，写“不许蒸馏”的条款就是霸王条款。字节、谷歌没做出 SOTA，未必是坚持不蒸馏，更可能是他们在赌全模态早期融合这种更难的路，加上大厂的股权激励留不住最想搏一把的人才。
小白视角解读：别把模型能力差距浪漫化成“谁有道德谁厉害”，技术竞争拼的是工程效率和人才激励。普通人能带走的判断是：选平台别只信营销叙事，要看它的组织在赌什么方向、最聪明的人在往哪流。

**7. 好 harness 必须有自己的取舍，万能的东西万万不能**
世界很脏，好的 agent 都做了一堆取舍，用优雅的接口包住丑陋的活。看各家客户端，背后都有很强的意见，agent loop 是写死的，只开放插件这种扩展点。而 DeepSeek harness 万事万物皆插件、什么都能改，当生产力工具反而很烂，跑正经代码任务效率不够高。但“怪异”对创业团队是加分项，现在大部分项目同质化到看一眼名字就能替它讲完整个 PPT。
小白视角解读：做产品别追求满足所有人，被一部分人讨厌也要有自己的立场。判断一个工具好不好，别数它的功能列表，看它敢不敢砍功能，砍得越有主见，越值得你用。

**8. 人人做三栏式客户端是走歪了，下一步是让软件变得可塑性**
现在每家做的 agent 客户端都长一个样，左侧任务列表、中间对话框、右侧预览，这条路快到头了。真正有空间的是可塑性软件，每个软件能被用户基于 AI 快速改造成自己要的形状。不是从零写一个剪映，那不现实，而是把现成的内核掰开重组成你自己的厨房。对企业也一样，不该逼它抛弃 ERP 换成聊天框，而是把 agent 能力接进它已有的系统里，传统软件加 agent 加胶水，这才是 agent 下一步渗透的路径。
小白视角解读：个人能带走的是“改”比“造”值钱。围绕你天天用的工具学怎么拆、怎么改、怎么拼，而不是想着什么都从零开发。软件正在从买来就定型，变成买来是毛坯、按自己的习惯装修，先拥有这种组合能力的人会赢。

## 信息差

**1. 你以为是常识的东西，可能只有圈内百分之一的人知道**
主播近距离接触一群企业家，发现有人连 codex 怎么安装、怎么绑信用卡都不会，要专门雇一个英国留学回来的小朋友上门刷卡装软件；连很多名字你听过的 AI 高科技公司，创始人日常工作都还在用豆包。他能随口报出一串模型新闻，是因为泡在圈子里，世界上绝大多数人对此一无所知。
小白视角解读：做 B 端、做服务的人最容易犯的错，是用自己的信息水位去推测客户。真相是信息差大到荒诞，客户的“笨”正是你的利润来源，所以别嫌客户不懂，更别假设客户懂，把每个服务环节都当成可能卡住的地方来设计。

**2. 顶级智能和够用智能的差距，对大多数任务没有感知**
教高中物理，用诺贝尔奖得主和用大学生，效果差不多。绝大多数工作是行政式、打杂式的，不需要最前沿的智能，真正必须用顶级模型的只有两类：竞争性工作和探索无尽边疆的前沿工作。这正是 OpenAI、Anthropic 增速放缓、开始谈上市的深层背景，市场在认真讨论“智能会不会变成水电煤”。
小白视角解读：别被最强模型的营销带着走，先问你的任务属于哪一类。大多数人的工作根本用不到 SOTA，把订阅预算花在流程和工具上，比换最强模型带来的提升大得多。这也是为什么顶级模型公司的增长天花板，比想象中低。

**3. 组织 AI 化最有效的做法，不是让员工学 AI，而是让 AI 顶替组织职能**
主播观察一圈后的结论是：有效的转型不是改组织让人用好 AI，而是直接用 AI 完成组织的职能，AI 是组织的竞品。他自己的实践就是样本，报 bug 的机器人自己去看线上日志和代码库来回答你，agent 每天扫线上报警分发到对应群，每周自动扫重复代码、坏设计、过期文档，把改好的 PR 推到人面前让你合并。
小白视角解读：大多数人转型 AI 的姿势是“我要学会用工具”，更该问的是“我手上哪些活是规则清晰、信息聚合、极吃责任心但不需要创造力的，能不能交给 agent”。把这类活交出去，人的时间才回到创新和判断上，这才是转型的真正杠杆。

**4. 协作正在从“飞书模式”转向“GitHub 模式”，人话越说越少**
内部体感是一个人干活经常比加一个人更快，因为任何交接、沟通、对齐都是效率损耗。现在的协作方式已经变成：有人问一件事，直接甩一个代码库链接，让他自己对着 AI 问；团队从人和人对话，变成所有人对着同一个单一事实来源写作。副作用是人和人几乎不说话，所以站会这种看似形式主义的同步仪式反而重新变得必要，否则团队会散。
小白视角解读：带小团队别迷信“多开会对齐”，先搭好单一事实来源，让文档、代码、数据都在一处、agent 可读，人和人只在需要判断和建立信任的地方见面。省下来的沟通成本，会直接变成团队的速度。

**5. 几百块钱加一台老电脑，就能攒出自己的语音管家，而且不绑任何生态**
主播的实践是拿一台跑 linux 的老电脑做中枢，跑开源智能家居软件，再接一个可编程的矩阵麦克风、一百多块的摄像头，就能在 Discord 里喊话控制全屋灯光、随时调看监控。核心是芯片和程序都能自己写，所以不绑定小米、苹果任何一家生态，想让助手叫什么就叫什么，想让不同任务路由给不同模型都行。
小白视角解读：别等大厂给你一个全知全能的家庭助手，那条路会被生态绑定锁死。真正的玩法是花几百块钱把中枢加麦克风加摄像头攒起来，把控制权留在自己手里。这跟做产品是同一个道理，先拥有能改的积木，才有定制的自由。

## 章节纪要

**开场：新闻太多，顺手定一个每周快评专题**
- 主播暑假在家带娃，因为嘉宾攒局临时录一期，顺便约定以后每周过一遍新闻，聊“哪件事重要、影响到底是什么”
- 点出本周关键词：OPC 热度下降、FDE 热度上升快到顶、腾讯把豆包和飞书合并全力推客户端、DeepSeek 的 Pro 模型评价两极、DeepSeek 还发了自家 harness

**OPC 为什么凉：只解决了“一个人能干活”，没解决“把钱拿到手”**
- 回答“做 OPC 最重要的是什么”：最重要是找到谁给你付钱；很多人天天自嗨我提效了，本质是哄骗同样想做 OPC 的人给自己钱，无源之水撑不下去
- 大部分从公司出来的人，没在市场上直接卖过东西，所以会不停逃避现实、不停做东西
- 两人共识：别攒了，先卖；做播客也一样，先录起来再说

**FDE 和外包到底有没有区别**
- 定义早就被用烂，现在自称以 FDE 形式交付的公司和外包没区别；早期区别是用咨询级的贵的人做交付，贵的人能边干边理业务，再把方法论沉淀回总部
- 过去咨询完还要花十个月写代码落地，所以才分化出埃森哲、IBM 这类把交付一并做掉的 IT 咨询
- 今天 AI 让研发成本极低，一个人对着 coding agent 口喷需求就交付完，FDE 因此显得惊艳
- 顺着追问：公司内部业务团队和 IT 为什么不自己这么做，还需要外部 FDE 吗

**企业为什么还需要外部 FDE：信息差、缺人、借刀杀人**
- 信息差比想象中大：传统企业老板连 codex 安装和绑信用卡都不会，要雇小朋友上门服务；很多知名 AI 公司创始人日常用豆包
- 传统企业利润薄、请不起高人，一家不小公司的研发负责人年薪可能才八十万，而且懂不懂还要乘以表达能力，内部人讲不清，老板也不信
- 外来和尚自带光环，现场开会一边讲一边上线八个 demo，老板当场觉得太落地了；本质是老板管不动高管，借外部咨询的刀推内部改革
- 主播立场：OPC 不成立但小团队成立，一个人能干的活超乎想象，任何交接都是损耗；但公司仍然有必要存在，人和人需要最低限度的沟通，站会重新变必要

**FDE 的终局：过渡职能，填完缝隙就消亡**
- 判断 FDE 不是长久业务，它填补的是企业渗透 AI 的缝隙，随着缝隙填满，这事最终该由企业内部员工拿着 agent 自己干
- 企业要解决的是业务问题而不是 AI 问题，餐馆得有客人来吃饭；缝隙填完，FDE 把能力移交给内部员工，再去下一家公司

**国产模型大放水：谁上了桌、谁翻车**
- 一轮至少四五个大发布：Kimi K3 口碑好、DeepSeek V4-flash 反馈好、Qwen 二十七亿小模型口碑好、DeepSeek Pro 评价一般甚至像发错了，还点了 Rock、Meta 的 MuSpark 等
- 主播自费实测，订了 199 元的 Kimi 等：给明确代码任务，已分不出和 GPT、Claude 的差别，自家 harness 拿去走 code review 再修复也能正常上线
- 体验吐槽：Kimi 刚上线算力不足、后台全是报错；Claude 很慢、Bro 快，所以日常问代码库问题常挂着快模型

**蒸馏争议与“字节、谷歌为什么没出 SOTA”**
- 蒸馏是自动获取更好模型训练样本的手段，账号和钱够就横向可扩展，ROI 极高；写“不许蒸馏”的条款是霸王条款，买了 API 想怎么用就怎么用
- 对字节谷歌没出 SOTA 的推测：未必是没蒸馏，可能是在赌全模态早期融合这种更难的路，毕竟它们多模态很强；加上大厂给不了最想要的人才那种创业股权预期，人才持续往外流

**智能会不会变水电煤，以及要不要买 OpenAI、Anthropic 的股票**
- 顶级模型公司增长放缓、两家都要上市，主播判断顶级智能只有竞争性工作和无尽边疆探索需要，大量普通工作用不上
- 买这类股票的逻辑是买保险而不是炒股：拿有限的钱押一个“万一未来所有公司都不值钱、只有它值钱”的巨大上行空间，顺便畅想小行星采矿、意识上传这类科幻级无限需求

**DeepSeek harness 拆解：不是好 agent，但是有意思的内核**
- 主流 harness 都对自己的 agent loop 有强主见，只开放插件这类扩展点；DSH 万事万物皆插件、什么都能改，当生产力工具效率不够高，连作者自己写 DSH 的代码都用的是 codex 和 Claude
- 但“怪异”对创业团队是加分项，现在大部分项目无聊到看一眼名字就能替它讲完 PPT
- 它真正值钱的思路，是把 harness 从静态的东西变成可以动态拼接的东西，这个方向值得借鉴，但和通向 AGI 的自我迭代叙事没有关系

**可塑性软件：每个人都该有自己的厨房工作间**
- 用两张工作间图片类比：每个厨子、电工的工作间布局都不一样，习惯用的锅铲调料不同，agent 和软件也该按人定制
- 为什么明明有现成客户端，还有一堆团队在做长得一样的客户端：因为每个人想要的东西不一样，这是真实需求
- 关键结论：定制不是从零造，从零写一个剪映不现实，而是基于现成内核用 AI 改造，相当于先抄一段代码再按偏好改；也可以等市场竞争逼出“原子化”的软件，再把想要的功能捡回来拼

**面向企业的下一步：agent 不该是聊天窗，而是插进你已有的系统**
- 正在做的一线方案是告诉企业不用装客户端，把 agent 能力注入它现有的 ERP 和流程，用“传统软件加 agent 加胶水”的混合形态完成 AI 转型
- 软件观的升级：买电视只能看电视，买电脑装软件就能扩展功能；过去软件太贵只能人人用一样的，未来软件可以人人改，但不是从零做，而是基于某个内核改成自己要的形状

**AI 原生组织的实操：用 AI 完成组织职能**
- 报 bug 的机器人常驻飞书，自动查日志、查代码库、定位到你的账户实况再回答；报警 agent 每天扫线上问题，分发到对应群
- 工程侧自动化：代码提交自动做质量检查、AI 自动 review、每周自动扫重复模块、不合理设计、过期文档，直接生成改好的 PR 推到人面前
- 用规则压住脏活：SVG 默认禁止手画，统一从选定开源库取图
- 非工程师也被推着用 AI：设计师直接拿到代码仓库自己改界面，只能提分支、由工程师检查，本地就能模拟线上效果预览
- 关键心法：别让人改习惯，把入口放在大家本来就在的飞书里，艾特一下就触发，比教育用户换工具好用得多

**结尾的两个念想：去二线城市看看，攒一个自己的贾维斯**
- 如果 AI 是巨大的社会变革，它不该只服务一千万人，该服务十二亿人；好奇洛阳、开封、绍兴、长沙这些地方的人用不用 AI、用不用 agent，已有线索是卖课和下沉 AI 推广的需求被反复验证，AI 乘自媒体就是当前副业供需两头都旺的切口
- 个人硬核玩法：老电脑装 linux 做中枢，跑开源智能家居，加可编程矩阵麦克风和一百多块的摄像头，在 Discord 里喊话控制全屋灯光、看实时监控，不绑死任何生态

## 思考

**概念先于业务被消费，判断新词要看有没有人给它定价**
OPC 火的时候没人追问“谁给你钱”，FDE 火的时候大家默认反正能收外包钱。同一个字面热度，一个没定义收款闭环，一个钉死了收费模式，所以一个凉一个热。抽象一层看，每一个新工种名词，OPC、FDE、prompt engineer、agent 操盘手，都是先被流量消费、后被商业验证。你能赚到的钱从来不取决于概念潮不潮，而取决于能不能回答第二个问题：谁付钱、付多少、为什么持续付。我见过太多人把精力耗在第一个问题上，反复论证这事 AI 能不能干，却从不回答第二个问题。结论：评估任何 AI 新身份，把收款闭环当第一性指标，闭环不清楚的名词再热，也只是别人的选题，不是你的生意。

**逃避式生产力是离职人的最大陷阱，卖是唯一的逃生训练**
“我先把能力攒够再开卖”，是几乎所有自由职业者共同的口头禅，本质和 OPC 玩家不停做东西一样，用熟悉的劳动逃避陌生的交易。他们不缺生产力，缺的是被拒绝的经验。可迁移的判断是给自己设一个比产出更硬核的北极星指标：上一次收到陌生人钱是什么时候。超过两周，就该把做东西的时间砍一半拿去买。先卖再做的逻辑在内容、咨询、软件三条路都成立，因为卖会逼你把价值压缩成别人听得懂、愿意掏钱的一句话，而这恰恰是做产品的第一步。攒能力永远攒不到头，被市场拒绝十次之后，你才知道该攒什么。

**能变现的信息差永远发生在你和真实世界之间，不在圈内**
主播被震惊的两件事，企业家不会装 codex、AI 公司创始人日常用豆包，对圈内人近乎荒诞，但这就是真实世界的分布。做 to B、做咨询、做出海最常见的死法，是把圈内共识当市场共识，然后抱怨客户不专业。抽象成方法：接任何业务前先做一次常识审计，把你默认人人都会的三件事写下来，逐条去真实客户里验证，大概率会发现其中两条是假常识，而每一条假常识都是一门生意。与其在行业群里卷信息，不如定期出去做陌生拜访，成本最低的调研就是去看客户到底在哪个环节笨，笨就是付费点。

**组织级变革要先画阻力图谱：谁受益、谁受损、谁来借刀**
高管推动 AI 不力，常被归因为能力不足或思想保守，但真相往往是位置决定立场，变革削他的权、动他的编制，他不是做不到而是不能做。这张图谱在所有组织里都成立，任何变革都要先画出受益者和受损者，直接受损的人会用一切合法的低效来对抗。给在组织里推 AI 的人，别试图说服受损者，去找真正的受益者，通常是能拍板但不愿脏手的老板。作为外部服务者，你的价值就是让他能借刀杀人又不失体面。给做服务的人更直白的一句：你的甲方永远是一个具体的人的利益，不是公司的 logo，谈单时找错人比报错价更致命。

**当模型层开始同质化，溢价会往上层的形状迁移**
这一轮国产模型集体摸到前沿，日常任务无差别，意味着纯卖模型能力的生意最先感受到压力，增长放缓、开始谈上市的，正是缺乏差异化护城河的那几家。历史规律很清楚：每一层技术一旦变成水电煤，利润就转移到它上面的封装、场景和渠道，云服务之上长出了 SaaS，基础模型之上会冒出一批把模型用出形状的公司。结论是别把自己的生意押在某一家的模型不可替代上，把模型当成可替换零件，把不可替代性建在数据、工作流和你对某个具体人群的理解上。模型每升级一次就重新洗牌一次，能带走的是那些不随模型升级而贬值的资产。

**产品是偏见，万能是诅咒，怪异是差异化红利**
DSH 被骂得最惨的“什么都能改”，恰恰也是它被神话的原因，两边都只对了一半：对一个生产力工具，没有取舍等于没有性格，用户不知道怎么用；对一次创新，长得和所有人一样等于死刑。抽象出的判断是，产品的竞争力来自砍掉什么而不是堆了什么，砍得越准，越有人爱也有人恨。现在 agent 客户端集体撞脸，谁都不敢砍功能，所以谁都记不住。做差异化产品时主动问自己：我砍掉的这个东西，是别人不敢砍的，还是我不该砍的。前者是立场，后者是硬伤。能守住前者，你已经赢过九成同质化的项目。

**从买软件到改软件，个人积累价值的方式要换**
软件历史上第一次从买来定型变成买来是毛坯，不是因为厂商发善心，而是改造成本被 AI 打到趋近于零。这个转变会重排每个人的能力结构：过去值钱的是完整造一个软件，未来值钱的是快速把现成软件掰成自己要的形状，再用原子化的零件拼回去。对自媒体和内容创作者的启示更直接，剪辑、排版、分发工具都在变成可改造对象，谁能先搭出自己顺手的工作台，谁就拥有别人抄不走的生产效率。把从零开发从你的能力清单里划掉，换成基于内核做裁剪、改造、拼装，这是普通人唯一能跑赢大厂软件团队的姿势，也符合“改别人的积木永远快过自己烧砖”这条朴素规律。

**组织的最小单元在变：先重建事实层，再谈对齐人**
协作从飞书模式走向 GitHub 模式，本质是信任的载体从对话记录变成单一事实来源，人和人之间的沟通损耗被压缩到只剩判断和创造。但主播也观察到反噬：人真的开始不说话了，站会这种低效仪式反而重新变得必要，因为信任还需要面对面的锚点。抽象成组织设计原则：先看你的团队成本花在哪，如果大量时间耗在对齐信息上，别急着加人，先建一个所有人包括 agent 都能读写的唯一事实层，把人只留在需要品味、拍板和承担责任的节点上。下一轮组织竞争力的分水岭，是谁先搭好“事实层加 agent”的底座，再用最小的人肉仪式维持住信任，而不是谁的人多、谁的会开得勤。
