# 播客干货 · AI 时代个人成长知识库

一个持续整理的中文播客知识库。我把自己听过、觉得值得反复看的播客，做成两两成对的笔记：一篇深度总结 + 一篇逐字稿。

你不需要一集一集去听几个小时，直接读总结就能拿到干货。想追原话，旁边就是逐字稿。

## 这里有什么

目前共 **115 期**，按主题分成 6 类：

| 分类 | 期数 | 大概在聊什么 |
|---|---|---|
| AI 工具与用法 | 16 | 具体工具怎么用、怎么落地到工作流 |
| AI 认知与商业 | 41 | AI 行业的判断、商业逻辑、赚钱思路 |
| Agent 与智能体 | 20 | Agent、工作流、AI 组织形态 |
| 产品与创业 | 14 | 产品思维、创业方法、出海 |
| 职场与个人成长 | 7 | 打工人怎么用 AI、个人能力建设 |
| 自媒体与内容 | 17 | 做内容、做 IP、写作、涨粉变现 |

每一期的笔记结构都是这样：

- 一篇**深度总结**：知识概览 + 适合谁听 + 重要观点 + 信息差 + 章节纪要 + 我的思考
- 一篇**逐字稿**：带时间戳的完整文字稿，方便追原文、做引用

## 文件格式说明

文件名格式：`YYYY-MM-DD--标题关键词-节目名.md`（逐字稿结尾带 `-逐字稿`）。

每篇笔记头部有一段 frontmatter，记录了来源信息：

```yaml
播客: "节目名"
单集: "单集标题"
发布日期: "2026-03-20"
时长: "1小时20分34秒"
链接: "https://原节目链接"
tags:
  - 播客笔记
```

用 Obsidian 打开就能直接浏览，总结和逐字稿之间有双链互跳。

## 怎么用

- **想快速了解某期讲什么**：读总结里的「知识概览」和「章节纪要」
- **想要可直接引用的观点**：读总结里的「重要观点」和「信息差」，观点都带原话或案例
- **想追节目原文**：读逐字稿，或用 frontmatter 里的 `链接` 跳去原节目
