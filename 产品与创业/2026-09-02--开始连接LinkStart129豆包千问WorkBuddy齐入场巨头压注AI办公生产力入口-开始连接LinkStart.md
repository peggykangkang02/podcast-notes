# 巨头杀进 AI 办公，创业者该怕还是该笑？这场会战的底牌被聊透了

平台：小宇宙｜时长约 78 分钟

## 知识概览

这期聊的是 2026 年夏最热的一仗：腾讯 WorkBuddy 跑到千万月活，字节把飞书挂到豆包体系下重推豆包办公，阿里千问办公跟进，国内巨头几乎同一时间把筹码押向 AI 办公。主持人张鹏拉来创新工场联合 CEO 汪华和 Flowbo AI 创始人谭少卿，一个从投资和巨头战略视角看，一个从亲自在 AI Agent 赛道创业的视角看，把这场会战从产品形态、商业逻辑到组织终局都拆了一遍。

两个嘉宾的视角刚好互补。汪华完整经历过移动互联网周期，熟悉巨头打法，开口就是“巨头最大的优势只有钱”，还拿自己同时订 200 美元 Claude Code 加 200 美元 Codex、让一群 Agent 互相抢攻当实验场。少卿做了快两年的 Agent 产品 Flowbo，起初纯做海外，恰好全程目睹巨头入场后自家中国用户的付费率、留存、活跃不降反升。一宏观一微观，配起来很有嚼头。

全程信息密度很高，硬数据扎堆：Claude Code 还没到千万月活时估值已到 200 亿美金量级，Harvey 用 130 张卡加一千多条轨迹把开源模型微调成能打的法律专有 Agent，训练一个原生模型核心团队只要十几二十个工程师，微调一个 Flash 级小模型十几张卡就够。这些数字全指向一个判断：AI 生产力这一层，大厂靠旧优势赢不了，创业者反而站在更好的位置。

听完会带走一个挺反直觉的结论：巨头这波进场不是来碾压创业者的，它更像一场免费的市场教育，顺便把中国用户被免费思维毁掉的付费习惯往回修。而对创业者真正的考验是别站到大厂车轮前，去做隔几层的非共识、做增量而不是降本、做新的生产关系而不是复刻旧办公。

**适合谁听：**
- 做 AI 应用和 AI SaaS 的创业者：巨头入场后怎么选切点、怎么定价、怎么避开大厂正面战场，这期给了很具体的判断框架
- 正在做出海 AI 产品的团队：中国用户付费习惯回摆的实证数据，以及中美渠道差、开源红利差的分析
- AI 观察者和自媒体：模型即产品、办公界面终将消失、大厂终局是水电煤这类能直接当选题的观点素材
- 天天用豆包办公、WorkBuddy 的普通打工人：听懂巨头为什么免费发红包、各家产品差异从哪看出来
- **可以跳过**：只关心 C 端娱乐社交 AI 的人，可略过后半段关于组织协同、多 Agent 编排、飞书归宿的讨论；完全不碰模型选型的人可跳读第二章节纪要和各家官网对比那几段

## 重要观点

**1. 巨头这波集体进场，才是中国 AI 真正的 ChatGPT 时刻**
汪华开头就下判断：有了大厂的推动，包括它们的补贴，才能真正开启中国 AI 的 ChatGPT 时刻。因为国内真正玩过 AI 的人其实很少，年初那波现象级 Agent 热潮（逐字稿写作“小龙虾”）只是技术极客的狂欢加好奇用户的外溢，很快散了。这次不一样：国产模型刚跨过性能门槛，Gemini Flash 级别的模型把成本真打了下来，大厂又把模型预装好、把 PPT、做画、办公这些日常场景替你设好，用的人多了场景才会长出来。早几个月模型能力不行，拿顶级 o 系才能跑，那种成本根本没法在中国普及。
小白视角解读：别把巨头当来抢饭碗的，它们是来砸钱把“AI 到底能干嘛”讲给全国人听的。没有这波补贴和教育，创业公司自己教育市场又慢又贵。所以巨头入场对创业公司第一反应不是防守，是接住这波被唤醒的需求。

**2. 一眼能看懂的下一步是巨头的，机会藏在隔几层的地方**
主持人问为什么最终是腾讯 WorkBuddy 把 Agent 办公封装成了大众产品，而不是当初创业者先做。汪华说得很直白：这种最泛化、最通用的消费级产品，大厂有流量、有资源、有前沿产品原生优势，创业公司去做，就是死死站在大厂车轮前面。他给创业者的方法论是：如果一件事是大家一眼就看明白的共识，大厂动作一定更快；要隔几层，去找非共识，或者在不同市场、不同具象方向上做出差别。
小白视角解读：通用入口、大众办公这种“谁都能看懂该做”的事，资源多的人一定会赢。普通人找机会要找“需要绕两层才想明白”的地方，比如某个行业的具体上下文、某种新组织形态、某个巨头看不上眼的小场景。

**3. Agent 会从以人为中心走向以 Agent 为中心，Copilot 只是过渡品**
少卿分享 Flowbo 的判断：他们从去年七月起就没打算做当前这种 Copilot 形态的产品，因为 Copilot 依然是以人为中心，你在旁边指挥、它补全。但随着 Agent 长程任务能力变强、越来越主动，会过渡到以 Agent 为中心，产品形态、交互设计、上下文设计全都要换。Claude Code 发布前，这个切入角度很反常识，被当成偏门的事，投资人也难理解；Claude Code 火了之后，质疑瞬间变少。
小白视角解读：现在流行的 AI 帮你写一半你来改，是过渡产物。趋势是 AI 自己把活从头干到尾，你在关键节点点头或摇头。挑 AI 产品时，可以多看一眼它是在“帮你干活”还是“替你干活”，后者才是下一代。

**4. 把 Agent 当生产力工具用，其实是用错了它**
主持人张鹏说自己聊了很多自己推 AI 推得很深的企业老板，得出一个规律：如果你只把 AI 当生产力工具，天花板就是你本人。它真正释放大价值，是在更大的上下文、更大的目标、更大的组织体系里，站到你之上、有鸟瞰视角。一旦它突破了你这个天花板，价值完全不一样，因为人愿意给比自己更牛的人更多钱，价值锚定就变了。少卿的 Flowbo 内部已经出现这种形态，Agent 会主动提议优化整个工作系统，确权后才动手改。
小白视角解读：用 AI 省时间只是第一层，那还是在拿自己的水平当上限。第二层是让它帮你做你本来做不到的事、管你管不过来的流程。判断自己用没用对，就看 AI 是在重复你的思路，还是在提出你没想到的做法。

**5. 模型即产品在 Agent 时代依然成立，字节输在不够开放**
聊到为什么 WorkBuddy 不是字节先做出来时，汪华点出一个关键：腾讯在模型上更开放，WorkBuddy 里可以择优选任何模型，字节的模型生态相对封闭也相对弱。在 Agent 场景里对指令遵循、长程任务要求高，模型不行，前端交互做得再好，结果出来就是不行。豆包那种偏对话式的体验对模型要求低，字节做得一直不错，但一到办公就露怯。所以“模型即产品”这句话到今天依然很重要。
小白视角解读：挑 AI 办公产品别只看界面好不好看，要看它底层能不能用上当下最强的模型。一个产品如果只能绑自家模型，而自家模型又不是最强，它的上限就锁死了。

**6. 大厂做 AI 办公能收到月费，这场仗它不亏**
汪华分析腾讯为什么把 WorkBuddy 当“村里的希望”加持：这个战场用户量级不像豆包那样几亿月活不可控，算力压力能承受，又能体现模型能力，还有高价值空间，关键是还能收一点订阅费，商业模式可行。对比豆包几亿月活只能压缩小模型，否则算力物理上都不够烧。所以 WorkBuddy 这类产品对腾讯是个很均衡的战场，不是某个团队想清楚了，而是赛马赛出来的幸存者。
小白视角解读：为什么巨头偏爱办公而不死磕聊天机器人？因为办公用户少但愿意付钱，聊天用户多但都是免费羊毛。能收钱的生意才值得巨头长期投入，这也是普通人判断巨头会不会坚持做一个产品的信号。

**7. 软件的界面正在消失，未来软件是给 Agent 用的**
汪华举了个扎心的例子：程序员本质只想要一段能跑的程序，不是要一个复杂 IDE。现在很多用 Agent 编程的人已经不开界面看了，直接说需求、拿结果，Claude Code 就是第一个放弃 GUI 编程交互的产品。推而广之，飞书这类办公软件，人要的是文档协同的结果，不是编辑界面，长远看飞书会变成被 Agent 调用的引擎，而不是被人直接点开用的东西。他自己现在做 3D 建模都让 Agent 通过 MCP 接口去操作软件。
小白视角解读：判断一个软件会不会被时代淘汰，就看它的操作能不能用一句话说清楚。能说清楚的部分迟早被 AI 接管，软件会从给人点的界面变成给 AI 调的接口，这是所有做工具的人都该提前想的事。

## 信息差

**1. 用户越多，模型越“智障”，这是物理限制不是产品失败**
很多人吐槽豆包模型笨。汪华解释这很正常：给几亿用户提供服务，模型性能调太高谁也烧不起，这已经不是价钱问题，是全国都没那么多算力给你调。所以豆包一直用很压缩的小模型，这不是字节不想秀肌肉，是用户盘子太大把算力摊薄了。反过来 WorkBuddy 千万级月活，反而能用上更强的模型，这是办公战场的一个隐藏优势。
小白视角解读：别拿“哪个产品模型聪明”直接比高下，先看它服务多少人。几亿免费用户的产品注定只能给你中等智能，因为每个请求背后都是真金白银的算力。

**2. 训练一个原生大模型，核心团队只要十几二十个人**
汪华说现在云厂商和开源框架都很成熟，训练原生模型（不是微调）需要的核心 research 和工程师，十几个二十个就够，外围再配几十人小团队。巨头的巨额用户基础并不会自动转化成新赛道的优势，Google 做编程工具，它的搜索和 YouTube 用户不会因此变成高质量编程用户。巨大组织反而会抵消算力和钱的优势，WorkBuddy 高概率也是内部小团队做出来的衍生项目。
小白视角解读：大模型训练的门槛已经低到超出多数人认知，所以别神话“大厂才能做 AI”。反而是大厂的组织惯性会拖累它，真正做出好东西的，往往是大厂里那些“不那么像大厂”的小团队。

**3. 把模型微调成垂直专家，成本已经降到十几张卡**
汪华透露 Harvey 这类法律 Agent 的做法：微调开源模型 K2，只用了一千多条强化学习轨迹、130 张卡，就把通用开源模型调成在特定法律任务上远超闭源旗舰的专家。如果微调的是更小的 Flash 级模型，大概十几张卡就够了。这意味着垂直领域的 Agent，小团队完全玩得起，而且大公司既不愿意做、组织架构也不适合做，连 coding 这种最大主战场大厂都没赢过，更别说法律、医疗这些细分。
小白视角解读：以前“做一个行业专属 AI”听起来要烧几千万，现在小团队也能干。真正的壁垒不在模型，而在你手上那一千条高质量行业轨迹数据，这是大厂没有也不屑于攒的。

**4. 中国做 AI 生产力创业，前几年欠的债现在还在还**
汪华直言国内生产力、企业应用这波起得比美国慢，是在还债：用户付费习惯被巨头免费思维毁掉，企业 SaaS 当年没真正做成（名义上做 SaaS，实际收服务费和定制费），也没有培养出真正成熟的销售通路。在美国一个创业公司做出好 demo 就能借成熟渠道扩量，不用自建大销售团队，国内这条路基本没有，得自己趟。
小白视角解读：为什么中国 AI 工具难赚钱而美国容易？不是产品差，是基础设施差：没渠道、没付费习惯、客户都等着定制。反过来这也是机会，谁先把这些洞补上，谁就吃到还债完成后的红利。

**5. 大厂这场 AI 办公仗其实打不大，地主家也没余粮**
汪华的判断有点反直觉：WorkBuddy 这场仗打不了太大。因为大厂都是上市公司要合规，得用国内算力、数据不出境，而算力还要分给模型训练微调、补贴 token。反而月之暗面、智谱这类模型公司更灵活，模型训好号称开源，但你要正经商用超过两千万美金就得来谈判分成，没算力没关系，可以借海外 AWS。而且国产算力、芯片供给一旦真起来，巨头要砸的钱只会更多，投入、基建、应用样样要钱。
小白视角解读：别被“巨头会战”的声势吓到，上市公司要算合规账和算力账，这场仗的烈度天然受限。真正灵活的反而是没有算力包袱的创业公司和新一代模型公司。

## 章节纪要

**开场：巨头齐入场**
- 国内巨头几乎同时发力 AI 办公：腾讯 WorkBuddy、字节豆包办公、阿里千问办公，身边很多人开始用、不少人薅 token 积分
- 两位嘉宾：创新工场联合 CEO 汪华（完整经历移动互联网周期）、Flowbo AI 创始人谭少卿（AI Agent 赛道创业者，去年七月入场）
- 主持人张鹏抛出主线问题：巨头动作背后对产业、创业者、用户各意味着什么

**中国 AI 的 ChatGPT 时刻**
- 汪华：大厂推动加补贴才能真正开启中国 AI 普及，国内真正玩过 AI 的人很少
- 年初现象级 Agent 热潮（转录稿写作“小龙虾”）是技术极客狂欢加好奇用户外溢，没持续很久，当时模型性能不够，顶级 o 系又慢又贵
- 与年初的本质区别：国产模型刚跨过性能坎，Gemini Flash 5.3、Flash 4、Deep 系模型把成本打下来，大厂才能大规模推广
- 大厂把模型预装、把 PPT、画图、办公等日常场景配好，用户量上来场景自然长出来
- 对大厂动作，汪华第一反应是“特别好”，创业公司自己教育市场的成本太高

**Copilot 只是过渡品，Agent 会走向以自己为中心**
- 少卿：Flowbo 从去年七月就判断长程任务会变强，瞄准的是 Claude Code 出现之前的空白，Copilot 形态只是过渡
- 过渡的原因：Copilot 以人为中心，技术成熟后必然转向以 Agent 为中心，产品形态、交互、上下文设计全要重构
- 现象级 Agent 产品让大众第一次看到“AI 能后台 24 小时运行”，Flowbo 第一轮融资在 Claude Code 发布后完成，此前切入这个方向被当成反常识
- 公测时用户抱怨一万积分很快用完，但追问后普遍对任务结果满意，因为干的活相当于初级实习生或助理半个月一个月的工作量，贵是因为没锚定在生产力意义上定价

**巨头教育市场，付费习惯开始回摆**
- 汪华：已有一批以程序员和专家用户为主的人坦然接受 68、98 元月费档，学生用户也在买，这是巨大进步，希望巨头顺便教育中国用户交月费
- 中国广告免费模式毁掉了付费习惯，而广告或交易支撑不适合所有商业模式
- 少卿：Flowbo 起初定价 40 美元每月只做海外，不区分国内定价，想验证用户是否愿为好产品付高价，结果中国用户付费远超预期
- 自证产品力：Flowbo 用 Gemini Flash 跑五个主流 benchmark 榜全胜 Claude Code 加 o 系顶配组合，且用的是官方 API 无法作假，之后顺势推出更便宜版本
- 数据验证：巨头入场教育市场后，Flowbo 中国用户付费率明显上升，月度留存和活跃持续上涨

**拆解 WorkBuddy 与三家产品性格**
- 少卿分析 WorkBuddy：交互逻辑完全从 coding 产品演变而来，进去是聊天面板加选项目文件夹，但知识工作者的文件系统是半结构化的，不像程序员把所有代码扔进一个仓库，说明没有重新设计
- 大厂真正发力点是专家模式：把 Agent 包装成各种专家（GPTs 形态的演变），降低小白理解成本，代价是对足够好的模型和 Agent 通常是降智的
- 从官网看厂文化：腾讯产品 UI 与其新版界面风格对不上，说明在快速仓促迭代、流量未必来自自有入口；千问办公更偏工程化、离技术更近；豆包办公更年轻酷炫
- 腾讯的产品哲学：不是官方路线图自上而下，而是底层小团队产品自然涌现、市场逐层印证、到节点后获得系统级加持，WorkBuddy 是赛马中活下来的那一个

**巨头为什么必须打这场仗**
- WorkBuddy 千万月活在巨头体系里不算多，但汪华提醒参照系：Claude Code 还没到千万月活时估值就已达 200 亿美金量级，单一用户价值极高
- 两个深层动机：一是豆包当年做出新入口的教训，没有巨头敢在一个东西还小的时候不重视；二是担心高价值的专业工作、生产力经济入口被错过，那可能不是白烧几十亿而是生死问题
- 巨头利润必须投出去变成面向未来的资产，美国对标公司一年两千亿美金的资本开支，国内打应用层战争真不算负担
- 办公是合适的战场：用户量不像豆包那样几亿不可控，算力可承受，能体现模型能力又有高价值空间，还能收订阅费
- 字节没先做出来的原因：现象级热潮时飞书吃到最多红利，字节重视过、做过一堆产品却没跑出来；关键差异是腾讯模型更开放，WorkBuddy 可选最强模型，字节只能绑自家相对弱的模型

**巨头哪些优势失效，美国 Agent 生态长什么样**
- 汪华：以美国为例，巨头没体现出绝对优势。唯一优势是钱，钱能换算力；但训练模型门槛已被云厂商和开源框架拉低
- 用户基础不自动转化，Google 做编程产品占不到便宜；巨大组织反而抵消资源，大厂做出好产品是因为里面有不像大厂的人
- 美国 Agent 生态分三层：第一层是 Office 365 和 Google Docs 里的办公 AI；第二层是通用 Agent 入口，Claude、Codex、Cursor 这类已不是办公而是全自动任务流；第三层是企业 Agent，分垂直行业（法律 Harvey、医疗、研发）和内部私有化部署两类，都是百亿美金级创业公司
- 值得盯的信号：价值从 coding 单轴开始向大量 non-coding 场景以 Agent 形态多物种落地

**开源红利与大厂该做的事**
- Harvey 用 130 张卡、一千多条轨迹微调开源模型做法律专有任务，性能远超闭源，中国为创业公司做的最好一件事就是大量开源模型
- 大厂既不愿也做不好垂直领域，成本效应和架构都不支持，连 coding 两大主战场都没赢过
- 未来企业级和垂直 Agent 大概率长在中国开源模型生态上：私有化部署只有五百强付得起，中国创业者在国产开源模型上的微调经验和技术圈交流有天然优势
- 开源模型可被蒸馏、借鉴、获取轨迹，不可能被闭源甩开太远，像当年的中国硬件供应链一样，离得近就是优势
- 大厂正确姿势是投资收购创业公司，像“生孩子”一样完成基因换代；美国巨头干得好的一件事是把算力、云、基础设施做到位，让创业公司容易生长

**中国市场的债与创业者现状**
- 国内生产力企业应用起得慢是在还债：用户付费习惯被毁、企业 SaaS 名存实亡、销售通路没建起来
- 少卿观察：身边创业者大多转型（转向离钱近的业务、深入企业做培训落地、代理海外 AI 产品），坚定做 Agent 方向的非常罕见，海外产品里一半以上用户其实是中国人
- 前景在好转：巨头把 AI 办公打成会战，创业者在旁边捡装备、借修好的路，练好本事后还能被巨头收编作为退出通道

**产品演进推演：从云端到 IM 到界面消失**
- 少卿如果当巨头产品经理会怎么做：坚定做云端聚合，不会从端侧和分布式切入
- WorkBuddy 该不该加 IM：应该加，Flowbo 今年四月就发了自己的协同层，因为飞书、企业微信这类 IM 是为人的协同设计的，多 Agent 接入时几百项权限根本没法用
- Agent 的运行时不会统一，把不同 Agent 协同起来的层才是更大的基建，里面流通的不是娱乐内容而是真实生产力
- 飞书挂到豆包体系下顺理成章：人最终要的是结果和协同，不是编辑界面，飞书会变成被 Agent 调用的引擎，就像程序员现在不再盯着 IDE 界面

**Flowbo 的现场实验：从同事到合伙人**
- Flowbo 有了 demo 后把绝大部分工作迁移到自己产品上，做生产力必须自己跑在上面
- 现场形态：本地盒子跑多个 Agent，接进人跟人的沟通群，报 bug 发截图或点击即写入，Agent 自己去飞书文档表格取数、拆解、修复、录视频交付，确认后 click review 走发布流程
- 更进一步：Agent 开始察觉并提议优化整个工作系统，确权通过后自己改进自己，角色从同事向偏 CTO、CO 的方向过渡
- 汪华补充实验：同时订 200 美元的 Claude Code 和 200 美元的 Codex，每周布置完全无人干预的开放题，Agent 之间会自己划分角色、互相抢攻、固执地往前推进
- 模型各有性格：o 系防御性编程强到一个程序写五千个回归测试，Claude 做事快，不同 Agent 用文档沟通、错题写进各自的开发手册，手册之间还会互相吵架

**这场仗的规模与 AI 时代的船票**
- 汪华预判 WorkBuddy 这场仗打不了太大：上市合规要求国内算力和数据不出境，算力还要兼顾模型训练和补贴；月之暗面、智谱的模式反而更灵活
- 国产算力芯片一旦供给上来，巨头要花的钱更多，基建、投入、应用都要钱，地主家也没余粮
- 少卿看产品：巨头要短期收入和规模，会适配现有组织造产品，专家模式这类对前期获客有利但对智能上限是倒退，所以巨头产品形态不会激进演进
- Flowbo 的选客逻辑：不做传统降本增效的大企业单，只做增量客户，关心能不能帮客户提上限、瞬时并发扩张，因为提上限的价值远高于降本
- AI 时代船票在哪：算力和基础模型是绕不过去的基础设施；生产力是一套全新体系，WorkBuddy 都不是最终形态，模型越强越不需要它；人最终需要的是一个 AI 个人助理
- 大厂的终局是铁路公司、自来水厂、电厂，做底层垄断，表层创新留给创业公司，微软的例子证明不靠惊艳创新也能成为极高价值的公司

## 思考

**巨头替你教育市场，你该做的不是防守，是搭便车**
少卿给了一个反直觉的数据：巨头大张旗鼓进场后，他自家产品的付费率和留存反而在涨。看穿这一点就不慌了，判断一个外部变量是威胁还是红利，别只看它和你是否同赛道，要看它是否在帮你降低用户从不信到信的认知成本。巨头补贴期本质是市场教育成本外包期，它负责把“AI 值得付月费”这句话讲进全国用户的脑子，你负责在它的动线末端承接被唤醒的增量需求。结论很明确：当巨头开始砸钱教育一个市场，你要做的是把自己放到用户被教育完之后的下一步里，而不是在巨头最强的通用入口上正面对线。这个窗口通常就一年左右，错过就真的是硬仗了。

**模型没收敛之前，产品层的最高杠杆是给用户选择权**
为什么连 Flowbo 都保留让用户选模型的功能？少卿的解释很到位：模型之间差异依然巨大，能让用户选模型，恰恰说明市场还没收敛到一家独大。这背后是一个可迁移的产品判断框架：凡是上游不确定性还很大的东西，产品就别替用户做死决定，把自己做成路由器而不是品牌商。等哪天模型能力收敛了，选择权自然会被产品收走变成默认值。做 AI 应用的人现在最该警惕的，是过早把自家产品绑定某一个模型供应商，那等于把身家押在一个还在赛跑的人身上。

**判断大厂会不会吃掉你，别数它的资源，要看它的约束**
汪华给了一套很清醒的分析法：巨头最大的优势只有钱，但它有钱也花不痛快，上市公司要合规、算力要兼顾训练和补贴、组织大了抵消执行力。所以预测大厂行为，永远不要从能力出发，觉得它什么都能做，要从约束出发，看它有什么不能做。判断你的切点安不安全，问三个问题：这个市场需要深度个性化吗，需要小步快跑试错吗，需要跟用户的上下文和算力深度耦合吗。三个都是，大厂就吃不进去。想通这点就不会被“巨头入场”的新闻吓到，巨头的威胁从来不在它要做什么，而在它适合做什么。

**Agent 的定价锚不是成本，是它替代的那个人**
用户嫌 Agent 干一小时活花两块钱太贵，可同样的话让实习生干要半个月，这里头藏着一个定价本质：生产力产品的价格参照物从来不是生产成本，而是用户心智里的替代品。Copilot 时代按人头订阅，因为它是人的附属；Agent 时代它的价值是替掉一段劳动力，那就该按那段劳动力的市场价来锚。做 AI SaaS 定价时，不要被 token 成本吓到自己，去算你的产品替代的那个岗位值多少钱，再决定收多少钱。谁先把用户的价值锚从“花了几块钱”扭到“省了一个人”，谁就掌握了定价权。

**把 AI 用成生产力工具，是你亲手封死了它的上限**
这期最扎我的一句话是张鹏转述的：AI 只当生产力工具，天花板就是你本人。工具逻辑下 AI 永远在复刻你的水平和速度，系统逻辑下它才可能站到你之上，鸟瞰整个工作流并反过来优化你和它的协作方式。少卿 Flowbo 里的 Agent 会主动提议改进工作系统，这个细节就是分水岭。落地判断可以看三个信号：工作流里有没有出现授权动作，有没有出现确权动作，AI 有没有开始对协作方式本身提建议。三个信号齐了，说明你已经在经营人机系统而不是雇佣一个数字员工。这个框架对个人创作者同样适用，别只问 AI 帮我省了多少时间，要问它有没有开始改变我做事的方式。

**界面消失不是突变，先消失的是过程能说清的软件**
汪华说程序员只要一段能跑的程序，不要 IDE，这话其实给了所有人一个判断软件命运的标尺：一个软件的 GUI 会不会消失，取决于它的操作能不能被语言完整表达、能不能被编程化。编程、建模、办公文档这类过程可语言化的软件，最先被 Agent 接管；而结果无法描述、需要人在回路里做审美判断的消费娱乐，反而安全。对做工具和 SaaS 的人，结论很硬：今天做产品就要默认你的用户里有 Agent，把能力和流程尽早暴露成接口，而不是只做给人点的高墙 UI。给 Agent 留后门的软件，才有资格活到下一轮。

**被免费思维毁掉的市场，会在王者换代时重新洗牌**
汪华说中国用户的付费习惯是被上一代互联网巨头的免费模式毁掉的，现在轮到巨头自己还债、把习惯往回修，而 Flowbo 的数据证明这个修复已经开始见效。这句话背后是个容易被忽视的判断框架：一个市场的付费习惯是被当前王者塑造的，王者换代往往就是习惯洗牌的窗口。所以别拿存量印象锁死自己，觉得某个市场的人不付费就永远不付费，要看是谁在塑造习惯、它正处于塑造的哪个阶段。对做出海的团队尤其适用，中国用户从“一切白嫖”到“68 块月费很坦然”，用了不到两年，这种拐点在其他新兴市场大概率会重演。

**开源模型把算力鸿沟抹平了，新的优势在供应链位置**
汪华两个数据连起来看很有意思：训练原生模型只要十几个人，微调垂直专家只要十几张卡，同时开源模型可以被蒸馏借鉴、不会被闭源甩开太远。这意味着核心生产资料正在变成可复制、可再加工的开源品，竞争从“谁拥有模型”转移到“谁离模型最近、最会用上下文”。中国团队的历史性机会就在这里，像当年电子制造离中国供应链最近一样，现在做 Agent 的人离国产开源模型生态最近，微调经验、技术圈交流都是别人拿不走的优势。别再把差异化押在模型本身，那是供应商的战场，你的战场是比对手更早摸到模型边界、封装成别人抄不走的垂直工作流。

**创业公司的退出通道，大厂正在替你修**
这期难得有人把大厂和创业者的关系讲得这么实在：巨头在场，对创业者既是参照物也是潜在买家。汪华说巨头该学会像生孩子一样靠投资收购换代，张鹏补了一句，练好的创业者能成为大厂的退出通道。这给所有 AI 创业者一个务实的心态框架：巨头不是你的对手盘，它是你的二级市场。你做出来的东西要么被用户买单，要么被巨头收编，两条路都成立时，你的动作会从容很多。真正的风险从来不是巨头太强，而是你的方向太普通，普通到巨头闭着眼都能自己做出来。
