# 不会编程的文科生，把 AI 跑步教练开源了

平台：小宇宙｜时长约 93 分钟

## 知识概览

这期的嘉宾毕飞很特殊：北外毕业的纯文科生，在一家美国科技公司做了七年远程，2025 年之前负责中国市场，没有任何技术背景。因为公司退出中国区，他被转去负责增长产品，公司扔给他一个 coding agent 账号让他自学，结果一年后他成了能独立开发的人，做出了佳明中国区 MCP、一个接入了多种手表数据的开源跑步教练 agent，还被小红书请去开发者生态圆桌当分享嘉宾。这期聊的核心不是技术，而是一个外行怎么被 AI 重新塑造成另一个职业身份。

节目大部分时间在聊这位嘉宾自己身上发生的事，但每件事都能抽出通用规律：为什么国产 agent 在春节火了一把又迅速没人用，为什么他说编程已经不值钱了而注意力才值钱，为什么软件越来越难当护城河而线下社群才是，AI 的记忆为什么总是不够用，应该怎么分层管理让 agent 真正记住你，以及一套课表为什么是死的而 AI 排课能是活的。两位主播本身也是 AI agent 的新手用户，提问非常贴普通人的困惑，嘉宾的回答又足够具体，整期信息密度高却很好懂。

价值点在于它同时覆盖了两个少见切面。一个是外行转型的真实路径，主播反复追问小白能不能上手，嘉宾直接给出冷启动方案，说把开源项目的链接发给任意一个免费 agent 就能引导安装。另一个是体育加 AI 的垂类观察，从跑步 app 市场格局、跨平台数据分析的空缺，到为什么看好线下的、真人聚集的体育社群，几乎每一段都能直接迁移到别的垂直赛道去类比思考。

**适合谁听：**
- 会用聊天式 AI 但还没用过 coding agent 的人，能听明白从 chatbox 到 agent 到底差在哪一步，以及该用什么成本冷启动。
- 做自媒体或内容运营的人，能拿到活人感、创始人个人号、官方号能量缩水这些实操判断。
- 对垂直行业加 AI 有想法的人，看一个跑步外行怎么拆解佳明、高驰们没做好的空隙。
- 想用 AI 管好自己训练、但搞不定记忆和课表的人，嘉宾给了完整的分层记忆方法论。
- **可以跳过**：最后二十分钟关于越野跑双人组、对向跑玩法设计的闲聊，以及开头两位主播对国产 agent 很长一段的使用感受铺垫，只想拿干货可从嘉宾自我介绍处听起。

## 重要观点

**1. 编程已经被解决，软件开发真正的门槛是用户洞察**
嘉宾引用 coding agent 创始人的判断，说绝大多数时候开发软件的限制已经不是写代码本身，而是能不能准确抓到一群人的真实需求、设计逻辑够不够清晰简单。只要软件别复杂到像重新做一个淘宝，一个小团体用的软件，靠对话沟通就能做出来。他自己就是这样从零做出各种项目的，嘉宾原话的意思是你可以是文科生、体育生，只要能跟它把问题沟通明白。

小白视角解读：过去做软件必须雇程序员，现在写代码这道工序变便宜了，就像排版曾经要专门的人后来人人都会。卡住普通人的不再是技术，而是你想给谁解决什么问题，这个问题问不清楚，工具再强也没用。

**2. 以后软件不再是产品，而是围绕真人服务的一小块工具**
嘉宾用一个类比讲了表达工具的演进：博客出现前普通人无处发表文字，后来能发图、发视频，现在 AI 让每个人都能写自己的软件。他判断软件会从巨头造给几亿人的产品，变成一个小团体自己维护、给一千个人用、一人一个月收点钱的 service。软件本身不珍贵也守不住，真正珍贵的是它周围那些线下服务和真人互动，报名只是生态里的一环，能把人从从不跑步带到去越野跑的那个社群才是门槛。

小白视角解读：别再把做个 App、写个小程序当事业核心，那只是入场券。能让人聚在一起、愿意持续付钱的是社群、服务、陪伴这些没法复制到网上的东西，软件是给它们做配件的。

**3. 没有护城河的东西，隔夜就会被复刻**
主播提出了反向观点，如果产品靠 Agent 就能做出来，说明它没有壁垒，你写出的新东西只要把描述放出去，第二天别人把描述扔给 agent 也能复刻一个。软件本身已经不讲武德了，很难再当护城河。这个判断同时给出了行动方向，做任何 AI 相关的东西，都要先想清楚哪一部分是别人复制不走的。

小白视角解读：现在判断一个点子能不能做，先问一句，如果我做出来，别人抄我难不难？难的部分值得投入，容易的部分注定会被卷平，不要为容易的部分熬夜。

**4. AI 时代被挤出来的时间，会流向线下真人体育**
嘉宾很看好体育赛道，理由是人一天的工作被 agent 消化掉大半后多出来的时间，会大量流向健身和体育。而这个领域恰恰是 AI 完全替代不了的，它必须真人、必须线下、兴趣驱动。他观察到越是用 AI 高效的人越需要线下出汗来对冲，线下活动、活人氛围会越来越值钱。

小白视角解读：当大量工作变便宜甚至免费，人的注意力会涌向那些必须亲身参与的事。想找风口，可以去找那些 AI 碰不到、必须真人到场才能完成的活动和服务，它们的稀缺性在升值。

**5. agent 的记忆要分层管理，核心记忆越短越好**
针对主播抱怨 AI 记不住事，嘉宾给出一套架构：agent 本身的核心记忆文件不要超过两百行，只写你是谁、要做什么、目标是什么这类高原则，具体偏好、伤病、训练数据全拆成独立文档放在旁边，让指令层去按需读取。主播把自己的记忆文件加到六千行的反面案例被当场纠正，因为每次对话所有记忆都要整体载入，超长只会让该看到的被挤掉。给新人下属不能直接甩八百页手册，要一层一层讲，agent 也一样。

小白视角解读：你以为记不住是模型笨，其实是把该放仓库的东西全塞进了随身口袋。要让 AI 真正记住你，别让它背百科全书，只让它记几条原则，细节要用到哪个调哪个。

**6. 会用的 agent 和好用的 agent，差在一个自我学习的闭环**
嘉宾说大部分人的用法是一次性单向指令，比如让 AI 每天扫五十个网站整理新闻，这其实是最简单的一层。再往上一层是让 AI 记录你的行为，哪些链接你点开了、哪些你读完，用你的真实行为反过来校准它下次推什么。他说这是 loop，你测量什么就得到什么，没有这个环节，AI 做一万遍还是老样子，就像做了无数顿饭的妈妈如果不反思为什么难吃，手艺永远不会进步，只有把反思融回下一次行动，一万小时才有效。

小白视角解读：用 AI 想让结果越用越准，就要给它设计一个能观察你反馈的通道，让它知道你做没做、满不满意。没有反馈回路的自动化，只是把同样的事重复一万遍。

**7. 死课表是上一代的身体在跑今天的课**
他批评很多跑团的课表是死的，每周二间歇、周四节奏、周六长距离，可你周二那天身体没准备好，硬跑只会全变成慢跑。他做的 agent 每天早上看睡眠、心率变异性、身体电量、伤病恢复再排当天的课，出差三天它会自动把最重要的课挪到出差前。他给自己定的原则叫 north star，先有明确的大目标，再一层层倒推每周每天，没有目标的人，AI 再好用也帮不上忙。

小白视角解读：固定排期是给人省事的设计，但身体状态每天都在变。不管是训练还是工作安排，与其死守日历规则，不如用当天的状态数据做输入来动态决策，目标越具体，这套动态系统越有用。

**8. 目标越明确，AI 越能帮上忙，没有目标的人用不好工具**
嘉宾观察到绝大多数跑者分成两极，一头觉得跑步根本不需要科学训练，另一头为了竞技成绩甚至愿意牺牲健康，中间真正会以安全和健康为前提去科学安排自己训练的人其实非常少。而工具恰好只对这批中间人有用，因为只有他们有明确目标可以被拆解，像他这种短期没目标的人就属于有点用不上。

小白视角解读：工具解决的是目标明确后的效率问题，它不会替你找到目标。先给自己定一个可检验的目标，再用工具去拆它，顺序反了会觉得所有 AI 都没用。

## 信息差

**1. 国产 agent 在春节爆火又迅速遇冷，和海外完全是两套逻辑**
嘉宾在美国工作，观察是春节前后那款在中文互联网被当成神灯的国产 agent，在他身边的工程师圈子里几乎没人用，影响力远不如 context 窗口变长的那两波更新。他评价这款产品给了全中国人一个假承诺，像一双带钉的越野鞋，看起来很厉害，真上山并不好使。他把国内的热情和国外的冷淡归因于传播方式不同，国内靠的是显性的新鲜感和大厂推手，而不是真实生产力。

小白视角解读：一款 AI 产品刷屏，不等于它真的好用，可能只是它长得很像未来。判断工具值不值得投入，别看它火不火，看用它的人是否真的把工作方式改了。

**2. 一个做跑步数据分析的开源项目，可能比主流 App 更懂跑者**
嘉宾吐槽现在的跑步 App 分两层，上层是佳明、高驰这种有原生数据的硬件厂，下层一堆主打 AI 或训练记录的应用，但它们宣传最多、做的最多的事其实是数据可视化，目的都是让你截屏发朋友圈。没人真正做跨平台跨项目的训练负荷分析。他做 agent 的初衷就是把不同手表的数据汇到自己手里，还要把力量、跑步、划船、越野这些项目折算成同一个训练负荷标准，因为佳明的负荷算法几乎只认跑步。

小白视角解读：大厂的产品逻辑是让你留在它生态里发好看的数据图，而不是帮你把数据真正用起来。所以主流产品留出的缝隙，往往是像数据主权、跨平台整合这种大厂不 Care 的角落，个人开发者恰好能钻进去。

**3. 你以为是 AI 记性差，其实是你把它该读的资料全塞进了脑子**
主播的 agent 总记不住指令，比如明明说了要用某个网页抓取工具，下次还是忘。嘉宾点破这不是模型问题，是上下文管理问题，聊天框只有当次会话的记忆，而 agent 的核心记忆如果写到几千行，每次对话都要整体加载，超出上下文的部分它就真的看不见。所以正确的做法是核心记忆短、细节外置成文档、让指令告诉它去读哪个文档，再加一层定期检查，像查岗一样看它对自己的描述有没有跑偏。

小白视角解读：AI 不是记不住，是它的工作台太小装不下你塞的东西。你负责分门别类，它负责按索引取用，把责任划分清楚，失忆问题基本消失。

**4. 手表上的心率变异性数据，厂商的算法可能不如你给自己写的**
嘉宾指出佳明的心率变异性用的是六十天滚动基线，导致他已经恢复了手表还说他没恢复。他自己改用最小有效变化原则重写了一个二十八天基线，响应更快也更贴合自己身体。这句话很关键，厂商给的是统计平均的通用逻辑，而个体差异只有自己长期记录才能捕捉，这是他坚持数据主权、自己写算法的原因。

小白视角解读：硬件厂商给你的每一个指标都内置了一套通用假设，它未必适合你。如果你真想用数据指导自己，别只信表上现成的评分，自己攒数据、用自己的节奏重新算一遍，往往更准。

**5. 训练社交的真正入口不是晒图，是让同频的人看见彼此的记录**
主播观察到运动打卡群里大家各用各的软件，如果有个地方能看见别人的完整训练记录，会特别有动力被 push 到。但市面上的软件要么数据单薄、要么没有社交。嘉宾补了一句，社交最难的不是功能，而是洞察一群人的真实使用需求，这也是为什么目前没人做得好。

小白视角解读：工具型产品常犯的错误是把分享做成晒成绩，而用户真正想要的是参照系，看到和自己水平差不多的人怎么练。做社群产品先别急着做炫耀功能，先做能看见彼此的记录墙。

**6. 大众聊 AI 都在说它多能干，真正的分水岭是它记不记得住你**
嘉宾把使用 agent 分成两个阶段，先花几周建立规则，之后进入长期的小步迭代期。他最看重的动作叫上下文工程，给自己搭一个能自动抓取所有背景的机制，让会议的纪要、邮件、聊天记录按人和项目自动归档，下次只要一句话他就能接上全部历史。他说这个自动抓取的机制建立起来之后，生产力是整体往上抬一截的，主播们刚用两周觉得又忙又没产出，其实还卡在建设期。

小白视角解读：和 AI 协作的前几周感觉效率变低很正常，那是在修管道不是在用水。判断你处于哪个阶段很重要，等管道建好，后面的省力是复利式的，不是线性的。

## 章节纪要

**开场与嘉宾介绍**
- 三位主播首次做视频直播，毕飞自我介绍，美国科技公司七年纯远程，自称跑者，一直用 AI 开发 agent。
- 主播说明想聊的话题，AI agent 对普通人生活工作的实际改变。

**主播使用 AI 的经历铺垫**
- 主播自述从豆包、千问这类纯聊天工具起步，春节知道小龙虾后尝试搭 agent 没成功。
- 后来把 agent 接进飞书群当全知员工，发现它经常答应做事转头就忘还道歉。
- 主播雨蒙分享品牌视角，让 AI 检索国内外跑鞋品牌的推广、运动康复、能量胶文献，发现给到的多是孤立报告，落不到生活里，于是开始追问品牌策略、生理、康复之间的底层逻辑，互动需求反复浮动。
- 雨蒙提到自己受过伤之后开始钻研肌肉、前置思考，也常把各种身份的想法随手记下来再让 AI 反问自己，帮她把想法从小程序重新定义成更大的体系，她觉得是在互相喂养。

**中美 AI 热度差的观察**
- 嘉宾说小龙虾激活了全中国的 AI 热情，但在他美国的工程师环境里 impact 很小。
- 他认为真正有革命性的是 context memory 变长，进入能写一整段工程的时代，此前主流 coding 工具还停留在代码补全。
- 他把小龙虾比作带钉的越野鞋，显性特征让人以为全能，其实是原型产品，这也是它现在没什么人用的原因，原项目开源免费，作者后来被大厂收编去做同类业务，但确实推动了一整代人开始有意识用 agent。

**国内 coding agent 价格战**
- 主播聊到国内一款背靠腾讯的 coding agent 排第一，微信广告铺天盖地，免费给大量积分，配合某款便宜模型基本等于不要钱。
- 嘉宾对比自己从 2025 年开始每月交一千五给国外工具，成本不在一个量级，但他质疑免费能否持续，普通人愿不愿意为模型本身付费是最大悬念。

**嘉宾的 AI native 转型**
- 嘉宾原是纯文科背景，负责中国市场，公司撤出后被转去做增长产品，公司给他一个 coding agent 账号让他自学，他靠对话学会了搭 agent 和做增长。
- 做出佳明中国区 MCP，希望跑步数据归自己、能跨平台分析。
- 最近被小红书请去开发者生态圆桌，嘉宾说开发者是他从未有过的新身份，像人生第二曲线。

**coding is solved，软件变 service**
- 嘉宾引用某 coding agent 创始人的话，说编程基本已被解决，限制在于用户洞察和产品设计。
- 用博客、微博、短视频类比，AI 让每个人都能写软件。
- 判断软件未来会变成一个小团体自己维护的服务，比如给跑团写个报名软件，一个人维护、一千人用、按月收费。
- 主播补一句，代码便宜了，注意力变贵了。嘉宾同意并指出软件护城河失效，别人拿描述就能复刻，真正的护城河在报名之后的线下社群和项目连接。

**为什么看好体育**
- 嘉宾说 AI 把人的工作时间压缩后，多出来的时间会流向体育健身，而健身完全无法被 AI 取代。
- 主播质疑 AI 解决了很多事却没让时间变多，自己反而问更多问题，怀疑是热恋期。
- 嘉宾区分 build 和 iterate 两阶段，build 期投入大，建成后底层生产力整体提升，建议坚持到秋天再判断，主播问 AI 是否推动了线下体育变火，嘉宾保留，认为大健康和减压需求也在起作用。

**跑步数据的个人史**
- 嘉宾承认自己数据控，但反过来提醒，如果你现在连手表里现成的数据都不看，就别折腾 AI 训练了，快乐奔跑就好。
- 聊到 VO2max 与有效生命的相关性，以及指标下降带来的焦虑，主播用 i 分和 UTMB index 下降举例共鸣。

**Agent 演进与长寿视角**
- 嘉宾从 2023 年末开始跑步，最初用定制 GPT，把丹尼尔斯方法论、某课表作者和自己的训练情况做成三个文档喂进去。
- 半马破 1 40 后意识到缺力量，发现自己健身只练胸肩背，因为臀没法拍照，点破男生也逃不开运动社交。
- 受过的伤让他转向长远健康，关心三十年后还能不能跑马拉松，重点盯力量增肌和最大摄氧量两个指标。

**记忆架构方法论**
- 嘉宾解释 session memory 限制，推荐给 agent 单独建一层记忆，核心记忆文件别超两百行。
- 主播自曝记忆文件加到六千行，嘉宾现场演示正确的四层结构，身份原则在最上，往下是 agent 指令层、技能层、对话层，伤病、营养、训练结果这类细节全部外置成独立文档，由技能层指示读取。
- 点出 human in the loop，agent 判断不了某个工具对你有多重要，大头决策必须人来定。

**自动上下文构建**
- 嘉宾讲工作中的做法，让 agent 定期读会议纪要、邮件、Slack 和飞书，按人和项目自动归档成笔记，再用 MCP 接通。
- 举例和索康尼的人通过一次电话吐槽鞋滑，几个月后再写提案时 agent 会自动把这段历史关联进来，讲过的忘了的都能补上。
- 主播呼应他们在腾讯会议纪要里用 AI 归类整理和碰撞方案，认为是落地里最值钱的部分。

**Loop 与可测量**
- 嘉宾批评一次性单向指令是最低层用法，高阶是让 AI 记录你的点击和阅读时长，反哺下一轮推荐，形成越用越聪明的圈。
- 强调 you get what you measure，阅读必须发生在能被统计的地方，比如让它把五十个站点整理成带统计的页面。
- 用妈妈做饭一万小时没进步做类比，反思要融回下一次行动才算数。
- 他给自己重写过 HRV 算法，用最小有效变化原则替代佳明的六十天基线，因为这些洞察来自每天使用，要沉淀成结构化原则再写回 agent。

**死课表与活课表**
- 嘉宾批评每周固定周二间歇、周四节奏的死课表，身体状态每天都在变，课表应该是前一天身体数据的输出。
- 理想形态是 agent 每晚看睡眠、HRV、身体电量、伤病恢复、天气和日程，第二天早上给当天的课。
- 主播延伸想法，希望 agent 给出多套备选方案自己选，认为自律的人会被安排得更严谨，生活不规律的人也能拿到浮动选项。
- 嘉宾强调要有 north star 目标，越具体 agent 越好辅助，目标本身才是决策，排课只是数据处理，他自己出差会先跟 agent 说，让它把最重要的课挪到出差前。

**目标与人群分层**
- 主播问这套东西怎么变现，嘉宾说跑团教练、赛事方可能就是渠道，但真正愿意以安全健康为前提科学训练的人是小夹缝。
- 多数人要么完全不在乎配速数据，要么为了竞技和面子愿意牺牲健康，中间人群很小，变现难但真实存在。

**创始人个人号与活人感**
- 主播观察公司官方号和产品号互动量远低于创始人个人号，判断官方媒体能量越来越小。
- 嘉宾举例某大模型公司最火的账号运营者是一个专门给人重置额度的员工，靠回复网友和竞品互动攒出活人感，反而是官方通知号没人看。
- 结论是以后内容都是矩阵，官方号负责发布，个人号负责互动，他本人也把社媒账号交给 agent 定时运营。

**攀岩与未来运动形式**
- 主播看好攀岩，理由是品牌都已布局产品线、国外成熟国内正复刻几年前的跑步打法，且攀岩既有社交属性又允许一个人去玩。
- 嘉宾认为这是未来运动能火的前提，不用凑一队人也能玩，越野跑、hyrox 渗透快也是这个原因。
- 从 hyrox 双人赛分项的分工逻辑聊到越野跑双人组其实是快等慢的负担，除非情侣或关系特别好。
- 主播提出对向跑玩法设想，两人从两端出发在中途交会，快的人多跑一段，可以做比赛也能制造趣味性，嘉宾认为有娱乐性才成立，纯竞技配队没动力。

**开源 agent 与新手上手指南**
- 嘉宾介绍自己用某 coding agent 建的跑步 agent，数据层打通佳明中国区 MCP、高驰 MCP、Apple Watch、训记等，高驰用的第三方逆向 MCP 比官方更好，松拓因用户少且自己不用还没做，鼓励别人 fork 出去做松拓版。
- onboarding 极简，把小红书的项目链接发给任意 agent，它会引导一步步连接模块，免费 agent 加便宜模型一天成本几毛钱。
- 每天流程，早上 agent 出 readiness score 排课，练完晚上分析训练与营养，新增微信机器人拍照自动算营养摄入。
- 嘉宾强调这事的出发点始终向内看，规则是自己身体的规律写成算法，再回头指导训练，而不是向外追别人的方法论。

**结尾闲聊**
- 主播们预告给听众送伴手礼，抽直播观众送眼镜，聊到每期都有装备福利送出。

## 思考

**外行转型的第一性原理是把对话本身变成生产力**
毕飞的全部资产起点只是能和 coding agent 说清需求，一年后他有了开发者身份。这件事的底层规律是，当工具的交互门槛降到自然语言，一个人的领域判断力、审美和洞察就直接兑换成生产能力，缺的不是技术训练而是敢把自己已有的判断投进工具的勇气。给普通人的结论是，不要再等系统学习完再动手，你的专业知识就是燃料，AI 是发动机，两者一接上就有输出。

**把记忆当组织架构，是驾驭长上下文模型的唯一姿势**
他给记忆分层的本质，是把无限堆料的人性冲动按住了。模型上下文有限是物理约束，但大多数人犯的错是把约束当缺陷去硬扛，拼命加长记忆文件，结果恰恰让关键信息溢出。可以迁移的框架是，任何和 AI 长期协作的系统都要设计成三层，常青原则短驻留、领域细节就近存储、具体任务显式调用，外加定期审计它对你的画像是否过时。结论是，与其训练 AI 记住一切，不如训练它知道去哪里查。

**工具的复利不在自动化，在反馈闭环**
一次指令换来的是固定输出，加上行为追踪才换来持续进化。这句话翻译成可迁移判断是，自动化的价值上限由它有没有被测量决定，测不到你反应的自动化只是原地转圈。做任何 AI 工作流都该先回答一个问题，系统怎么知道我做没做、满不满意、下次该不该这样，有这个环才配叫资产，没有就只是脚本。所以结论是，设计工作流时把埋反馈点放在写功能之前。

**当技能趋近免费，价值必然逃向必须肉身在场的地方**
他看好体育的逻辑本质是一个价值守恒判断，凡是能被代码重写的部分都会快速贬值，凡是不能被代码重写的部分都会相对升值，而线下真人互动恰好卡在代码够不到的位置。这个框架可以迁移到个人选择和创业判断，别跟 AI 抢它擅长的活，去找那些天然要求信任、身体、现场感的位置站。结论是，评估任何一个 AI 项目，先找出它离线的那一半，那一半才是定价权所在。

**固定排期是上一代人的效率观，状态驱动才配得上实时数据**
死课表被批不是因为不努力，而是它用日历规则代替了对当下状态的判断，这背后是两种管理哲学的冲突，一个按计划表推进，一个按状态输入重算。当你手里有连续的状态数据，按状态驱动永远优于按日历驱动。这个判断对内容排期、销售节奏同样成立。结论是，如果你每天都能拿到自己状态的信号，就别再让星期几替你决定今天干什么。

**厂商卖的是平均数，你真正要的是针对你的那条曲线**
他重写 HRV 基线说明一个隐蔽事实，硬件大厂的所有指标都内置了统计平均的假设，而个体差异恰恰落在平均线两侧。信现成评分是把身体外包给陌生人的统计。更深一层，数据主权之争不是隐私问题，是解释权问题，谁定义指标谁就掌握了对你的评估。结论是，重要数据要自己攒、自己建基线、自己保留解释权，模型和硬件都只是跑腿的。

**工具用不好，大多数时候是目标没有具体到可以被拆**
他把用户分层的观察其实暗含一个更尖锐的判断，工具只会放大你已有的明确性，不会替你生成方向。没有 north star 的人觉得所有 AI 都鸡肋，有目标的人嫌工具不够强，差异不在工具而在目标的可拆解度。所以普通人卡住的时候不要急着换工具，先把模糊的愿望降维成可检验的指标，再回头看工具，答案往往已经在那里了。

**AI 越普及，越考验人处理自己无聊和焦虑的能力**
主播们聊到用 agent 后时间没变多反而更忙，嘉宾则建议把该修的管道修完再评价，这两种状态其实对应同一件事，技术省下的时间不会自动变成自由，只会先变成更多的问题和攀比。看到 VO2max 和积分下降就难受的人，和追着让 AI 记住自己却不肯删文件的人是同一种心理，把外物当成了自我评价的锚。结论是，工具的终极使用姿势是向内看，把规则、数据、解释权都收回到自己身上，让模型只做执行，这样才能既享受生产力又不被它绑架。
