# 总结 · 乱翻书《Vol.270 大厂押注 AI 办公，飞书和钉钉却先成了配角》

嘉宾：艾瑞克（前飞书商业化 + 产品团队 4 年）、屠龙之术主播明浩、亚楠（前字节，行业观察者）｜主播：潘乱

时长：约 97 分钟｜来源：小宇宙 乱翻书

## 知识概览

这是一期围绕「飞书被分拆进豆包体系」这条突发新闻，把腾讯、字节、阿里三家 BAT 大厂的 AI 办公战争串起来聊的行业拆解直播。三位嘉宾分别从字节离职员工内部视角、行业观察视角、媒体视角交叉印证，知识集中在五块：

1. **一条新闻的真相拆解**：飞书这次调整到底发生了什么，产品、商业化、研发三条线分别去了哪，为什么说「豆包企业版」这个产品其实不存在，真相是买豆包送飞书
2. **一个战略命题**：豆包两亿日活到底是资产还是负债，C 端三条变现腿为什么全废，AI 的变现逻辑和传统互联网为什么是两种完全不同的生意
3. **一次范式转移**：为什么半年间全行业从卷 C 端聊天（豆包/元宝/千问发红包）转向 coding as harness 和办公 Agent，coding 为什么成了这轮 Agent 大战的地基
4. **一场产品形态之争**：个人生产力 vs 企业办公的边界怎么越来越模糊，付费者到底是谁，为什么腾讯的 WorkBody 能从边缘长出来而大厂主推的产品全挂
5. **一个时代的赌注**：未来 AI 的钱主要从 C 端还是 B 端来，飞书钉钉这对打了五六年的冤家，为什么最后都不是被对方击败，而是双双变成 AI 大故事的配角

**小白视角一句话**：这期在回答：飞书钉钉这些老牌办公软件，为什么一夜之间被 AI 抢了主角位置。答案是 AI 时代赚钱的逻辑变了，靠卖办公软件席位收年费那套跑不通了，大厂都在赌 AI 到底该找谁收钱，而飞书钉钉手里最有价值的只剩它们攒下来的企业数据。

**适合谁听**：做 AI 产品或 SaaS、想搞懂大厂 AI 商业化到底怎么走的人；运营个人 IP 或做工具想搞清楚「该收 C 端的钱还是 B 端的钱」的独立开发者；被各类「豆包要分拆飞书」新闻绕晕、想听内部人讲真话的行业观察者。纯 C 端玩家可跳过中间组织架构细节，但「付费者可能是个人而不是企业」和「中层最容易被 AI 替代」两段值得听。

## 重要观点

**观点一：飞书这次不是「拥抱 AI」，是被拆进 AI 体系当底座，因为 AI 时代的想象空间和付费意愿都压在模型身上。**

原话（艾瑞克拆完三条汇报线后）：从商业化看是两个销售团队合并、避免互相抢客户；从产品看是「豆包企业版」团队原来就是从飞书产品团队借调的人，现在又汇报回谢欣；研发线没变。「站在张一鸣的角度，两个销售团队合并了，你们效率提高了，不用再互相抢客户了」。

案例：所谓「豆包企业版」产品根本不存在，它就是飞书企业版里加了一个名字叫「豆包」的机器人。火山引擎的销售卖法是「买豆包企业版，我送你飞书企业版」，因为老板更愿意为 AI 付钱，你说买办公协同老板觉得不重要，你说公司要变成 AI native 团队、买豆包的 token，老板才掏钱。反过来飞书的新签和老客户增购，主要驱动力也早就是 AI 功能了。

小白视角解读：别被「飞书分拆」这个说法误导成飞书不行了。真相是两边本来是两套销售班子抢同一笔预算，现在合成一套，效率更高。但真正的信号是主次关系变了：以前 AI 是飞书的一个卖点，现在飞书成了豆包的一个底座，因为老板的钱是冲着 AI 模型去的，不是冲着办公软件去的。这告诉我们，在 AI 时代谁站 C 位不是看谁产品打磨得好，是看谁的名字能让人为想象空间掏钱。

干货结论：看大厂 AI 组织调整，别只看新闻标题谁吞并谁，要看钱从哪端进来、汇报线朝哪个方向收拢。资源永远是跟着「老板愿意付费的那个概念」走的。

**观点二：豆包两亿日活是「负债」而非「资产」，因为 AI 的生意是每多一个用户就多一份计算成本，和互联网完全不同。**

原话（艾瑞克）：互联网的思维是把规模做大、用边际效应覆盖成本，但「AI 不是这样子，AI 是有一个用户就多一份计算的成本」。豆包一天大概有百万亿级 token 的使用量，换算成本一年大几百亿人民币，而且「C 端用户简直是甩都甩不掉」，在没有变现途径的情况下非常岌岌可危。

案例：豆包不是没试过 C 端变现，而是三条路全试过全废了。第一条走 GMV，问它哪个吹风机好会弹商品卡，跳抖音商城，但唤起的是独立商城 App，因为唤起抖音大家就刷抖音去了不买了，单量也就几万单，对字节的广告体量九牛一毛；第二条走品牌广告（GEO），但一插入广告用户就再也不信任这个问答产品了；第三条走个人付费订阅，付费率低到「令人发指」。所以字节内部也总结过：做大事的部门如朝夕光年、大力教育都要尽快证明能变现，梁汝波说 All in AI 但耐心也没那么高。

小白视角解读：这是整期最反直觉的一点。按传统互联网逻辑，用户越多越值钱，所以大家本能觉得豆包两亿日活是天大的资产。但 AI 的成本结构反过来了，每个活跃用户都在烧钱，光算 token 消耗一年就是几百亿人民币。所以大厂看豆包，不是看它有多少用户，是看它能不能把这笔钱挣回来。你做一个 AI 产品也一样，别被「用户量」冲昏头，先算清楚每个用户是给你带来收入还是带来成本。

干货结论：判断一个 AI 产品的健康度，别只看 DAU 和留存，要算单位用户的经济账。用户多但算不过来账的 AI 产品，在大厂眼里是甩不掉的包袱，不是资产。

**观点三：AI 是卖铲子的生意，只有 B 端（从事生产的人）有付费意愿，C 端用户在 AI 时代没有价值。**

原话（艾瑞克）：AI「本质上是卖挖金子的铲子，它还是工具，工具是用来提效的。谁有买工具的需求？就是提高生产力的需求，肯定是从事生产的人。所以他只有 B 端，只有 Anthropic 这个路从一开始才是对的，其他的 C 端用户真的在 AI 时代是没有价值的」。

案例：他用数据佐证，Anthropic 的收入已经超过了 OpenAI，但只有这两家大模型公司收入过了 500 亿美金，第三名只有小几十亿美金。因为真正为 AI 付钱的是 coding 和普通信息搜集这类生产力场景，Claude 的主要付费用户不是 C 端闲聊的人。嘉宾还观察到，中国大部分能接受到 coding 层次的用户早就被 Cursor、Claude Code 洗走了，国内厂商真正能抓住的是原来没被任何工具覆盖的非 coding 白领人群，而这些人正是更容易产生 token 消耗和付费价值的。

小白视角解读：一句话戳破「AI 人人能用」的幻觉。工具是拿来提效的，只有本身在生产、有活儿要干的人才会为提效工具付钱。闲聊、问八卦的 C 端用户爱用但不掏钱，真正掏钱的是写代码的、做 PPT 的、写方案的打工人和企业。这解释了为什么 AI 公司抢着做 coding 和办公，因为它们瞄的是「有生产任务的人」这个付费人群。你做工具型产品，先想清楚你的用户是「在生产」还是「在消费」，后者很难收到钱。

干货结论：AI 产品要找的付费人群是「有活干、要提效的人」，不是「有闲、想聊天的人」。做产品前先分清用户是在生产还是在消费。

**观点四：腾讯 WorkBody 能从边缘杀出来，恰恰因为腾讯没有 to B 的牌、只能做个人本地数据的 to C 产品；而「凡是老板盯上的产品一定会死」。**

原话（艾瑞克 + 明浩 + 亚楠交叉）：艾瑞克认为「WorkBody 没有任何门槛，如果腾讯能做 to B，它不会去做 WorkBody。腾讯没有 to B，它只能做 to C，它抓不到企业内部在线数据，只能抓本地数据」。亚楠补：「凡是老板盯上了的产品一定会死，因为他一旦关注，动作就会变形」。WorkBody 是先长出来才被关注的，「从一堆苗子里选出来一个优等生」，属于原生家庭托举，不是自上而下的 All in。

案例：对比极其鲜明。腾讯举全公司之力、老板亲自压大注的产品全挂了：微视干不过视频号、元梦之星、元宝这些在腾讯自己定义的主战场上「自己主动压的最大的牌，表现都很差」。反而 WorkBody 是边缘的 code body 团队（做代码的产品）顺手做给非 coding 人群的小东西，先自己长出来，靠两天一更新的极快节奏跑起来，被看到后才被投广告托举。而字节这边，几个成熟团队（飞书、扣子、翠）协同搞一个产品，中台机制消耗大量协调时间，反而是劣势。

小白视角解读：这里藏着一个反直觉的组织洞察。通常觉得大公司有钱有资源、老板重视的产品一定赢，但结果相反，老板盯得越紧、举全公司之力的产品越容易变形失败，因为动作会为了迎合老板而扭曲。真正跑出来的是没人盯着、可以快速试错的边缘小团队。WorkBody 能赢不是因为它有多强，是因为腾讯在办公上没有历史包袱、只能从个人本地文件这个别人不要的缝里切入。做产品别迷信「资源倾斜」，轻装上阵、能快速迭代往往更接近正确答案。

干货结论：老板重视 ≠ 产品能成，边缘小团队 + 极快迭代节奏，往往比举全公司之力更能抓到 AI 时代的窗口。判断一个团队能不能做出好 AI 产品，看它能不能两天一更新、有没有沉重的 KPI 包袱。

**观点五：AI 办公的付费者可能不是企业采购，而是个人员工，个人生产力与企业办公的边界正在模糊。**

原话（明浩）：作为个体户「我给那些大模型充的钱，应该已经比飞书的钱多了」，苏州当老师的姐姐也用 WorkBody 做高中备课，「这明显是一个个人为自己的工作场景付费的行为，他不会想到去下载一个飞书、用钉钉来学这些」。最终落点是「AI 办公的付费者可能不是企业采购，而是个人员工」。

案例：三位嘉宾一致观察，国内 B 端需求其实很多是 C 端付费。WPS、腾讯会议的付费大部分不是以公司为单位采购，是个人用户自己掏钱。员工哪怕公司采购了企业版，可能依然把它当个人助手用。这导致 AI 办公变成一个「卡在 to B 和 to C 之间」的模糊地带，既不能叫 to B 也不能叫 to C，应该叫个人的生产力。评论区的共识是：个人生产力跟工作增长力的边界正在模糊。

小白视角解读：过去做企业软件，逻辑是企业统一采购、按席位收费，付费决策者是老板或 IT 部门。但 AI 办公不一样，掏钱的人越来越多是那个自己觉得「不用 AI 会被会用 AI 的人替代」的普通员工。这意味着做 AI 工具，你的付费设计不能再只盯着「卖给公司一套」，而要能打动「个人愿意为提升自己生产力而买单」。对企业软件创业者这是巨大的机会，也是对旧采购模式的颠覆。

干货结论：AI 办公市场真正的付费单元在从「企业」下探到「个人」，谁能让个人觉得「这工具能保住我的位置、提升我的产出」，谁就抓住了新的付费人群。

## 信息差 / 反直觉

**1. 「豆包企业版」是个不存在的产品，它是飞书企业版加了个叫豆包的机器人。** 新闻稿里的豆包企业版内测，真相是飞书企业版里嵌入一个叫「豆包」的 AI 机器人。销售卖法是买豆包送飞书，因为老板只认 AI 的概念。这也解释了为什么产品团队要汇报回谢欣，因为豆包企业版的本质还是飞书的产品，只是借了豆包的名。

**2. 大厂办公 Agent 大战里，真正让飞书钉钉变配角的是「老产品改造」太难，而不是新对手太强。** 讨论到为什么飞书钉钉做不出通用办公 Agent 时，结论惊人一致：在原有产品里做 AI 改造，比新做一个产品难太多。飞书 2023 年就想做 AI 原生大改版（齐俊源的 AI First），但步子太大老客户不满意被否，得出「企业服务只能改良不能改革」。反而是没有历史包袱的 WorkBody 这种新产品能放开手脚。所以老板掏钱买的是新故事，不是老产品的改造。

**3. 豆包真正的价值不在自己变现，在给抖音广告喂用户画像，羊毛出在猪身上。** 豆包自己 C 端三腿全废，但嘉宾点出它和抖音、巨量引擎账号互通，豆包积累的用户画像质量比抖音原生数据高一个量级。字节近千亿美金广告收入，算法越懂你推荐越准、ROI 越高商家越愿意投，哪怕只提升 1% 就是十亿美金。这才是豆包藏在冰山下的价值。

**4. 互联网人的「A/B test 数据驱动」这套打法，在 AI 时代失灵了。** 字节引以为傲的 A/B test 文化在 AI 面前被认为土崩瓦解，因为没人知道正确答案、没有北极星指标，A/B 浪费时间、中台机制消耗协调成本，等你测完腾讯 WorkBody 已经甩开一大截。评论区的痛点总结是「数据驱动没了，不会做判断了」。传统互联网的「用户量上去了价值自然有价格」在 AI 上不成立，有价值的东西可能没有价格，得先想好从哪端收费再动手。

**5. 办公 Agent 的本质是把 coding 藏到界面后面，coding 是这一轮所有 Agent 大战的地基（coding as harness）。** 表面看办公 Agent 是面向白领、用自然语言的，但嘉宾指出它背后依然是 coding 和工具调用能力，是「把 code 藏到了界面后面」。coding 不只是 coding 本身，它成了 agent 和 harness 的核心构成，无论预训练后训练、评估打分、自主进化都基于 coding 能力来基建。这是当下最头部厂商都承认的共识。

**6. 中层是最容易被 AI 替代的，焦虑感也最大。** 推 AI 办公时，老板热情、一线员工也热情（怕被会用 AI 的人替代），但中层反而是焦虑感最大的。因为很多公司中层主要起上传下达作用，一旦企业信息数据化、一线员工创造的信息能被 AI 直接抓取，上传下达这个职能是最容易被 AI 取代的。

## 章节纪要

- **开场 + 新闻引子**：三位嘉宾确认今天要聊 BAT 的 AI 办公战争。半年前当红炸子鸡还是豆包/元宝/千问（发红包、两亿日活），如今五家全成了「明日黄花」，注意力全转向 AI 办公，怎么回事。
- **飞书分拆的真相拆解**：前飞书员工艾瑞克从商业化、产品、研发三线拆解。商业化是两套销售团队合并（消除互相抢客户），产品是豆包企业版团队本来就是从飞书借调的人现在汇报回谢欣，研发线没变。站张一鸣角度就是销售合并提效。
- **豆包需要飞书还是飞书需要豆包**：核心争论。艾瑞克认为绝对是豆包更需要飞书，因为豆包急需一个像 Anthropic 那样通过 to B 变现的入口；明浩补充两边互补，豆包 to B 需要飞书的入口和数据。
- **AI 是卖铲子的生意，C 端没价值**：AI 只有从事生产的人（B 端）才有付费意愿，Anthropic 收入已超 OpenAI，只有两家大模型公司收入过 500 亿美金。
- **为什么从 coding 转向办公 Agent**：半年前全行业在卷 C 端，为什么现在全转 coding as harness 和办公 Agent。Claude Code 的巨量收入爆发 + open cloud 春节爆火带来的示范效应；中国非 coding 白领人群是没被抓住的付费金矿。
- **为什么通用办公 Agent 没从飞书内部长出来**：飞书有文档知识库会议 CRM，理论上最该长出来，结果被隔壁腾讯做 code 的边缘产品 WorkBody 先做出来了。原因是腾讯最焦虑、没 to B 牌只能做个人本地数据；有飞书的人觉得捡 WorkBody 那种个人数据是捡垃圾。
- **飞书的智能问答和「开天眼」**：艾瑞克讲飞书最有价值的不是协同，是 AI 智能问答能抓取企业内有权限的全部文档。管理层能「开天眼」，员工没权限的文档，老板一搜也能看到答案，这才是企业最值钱的东西（马化腾没法让 WorkBody 抓十几万员工的本地数据）。
- **个人生产力 vs 企业办公边界模糊**：付费者可能是个人而不是企业。WPS、腾讯会议多是个人付费。苏州老师用 WorkBody 备课是个人为工作场景付费。中层焦虑感最大因为上传下达最易被替代。
- **赌 C 端还是 B 端**：这场办公 Agent 大战的终极赌注。如果钱主要来自 C 端，那是入口为王（WorkBody 这种）；如果来自 B 端，飞书这种企业原生数字化资产模式更可行。企业 IM 的历史使命可能已经完成，新的是数字化 AI 的全新议题。
- **腾讯的组织逻辑：凡是老板盯上的产品一定死**：微视、元梦之星、元宝这些举全公司之力的产品全挂，反而边缘 code body 团队先做出 WorkBody。它是先长出来被托举，不是自上而下 All in。团队更新节奏两天一版。
- **字节的问题：中台惯性 + A/B test 失灵**：字节多个团队协同搞一个产品，中台机制消耗协调时间；A/B test 这套在没人知道正确答案的 AI 时代失灵。互联网的「先做大规模再谈变现」在 AI 上不成立，有价值的东西可能没价格。
- **豆包 C 端三条变现腿全废**：GMV（商品卡跳转单量几万单）、品牌广告 GEO（影响用户信任）、个人付费（付费率低到令人发指）。豆包反而从不告诉你 token 额度不够，因为它是流量入口，不能因付费门槛流失用户。
- **豆包的隐藏价值**：和抖音、巨量引擎账号互通，用户画像质量质变，喂给抖音广告算法，羊毛出在猪身上。这比豆包自己的 C 端付费价值大得多。
- **coding as harness 共识**：coding 能力成了 agent 和 harness 的核心，是模型训练推理、自主进化、评估打分的基础设施。办公 Agent 只是把 code 藏到界面后面。Codex 定义了 work agent 的三栏产品形态共识。
- **BAT 更看好谁 + 收尾**：开放式问题没结论。腾讯从 WorkBody 出发要接腾讯文档做 AI 时代的 Office；阿里把千万/罗罗子快跑/code work 合成新钉钉；字节把飞书产品团队并入豆包。嘉宾认为这些都是过渡，后面还有更大家伙等着。

## 思考

**判断一个 AI 产品的健康度，别只看用户量，要看单位用户经济账。**
互联网时代用户多是资产，AI 时代用户多是负债，因为每个活跃用户都在烧 token 成本。豆包两亿日活却要一年烧大几百亿，自己算不过来账，只能靠喂给抖音广告来暗度陈仓。这对所有做 AI 工具的独立开发者是个警钟：别用传统互联网的「先圈用户再变现」思维做 AI，你会被成本拖死。做之前先想清楚每个用户是给你带来收入还是带来成本，算不清账的增长是慢性自杀。

**AI 只服务「在生产的人」，不服务「在消费的人」，找付费人群先分清这个。**
卖铲子逻辑是这期最有普适性的一句话。工具的价值在提效，只有手头有活干的人才为提效付钱。这解释了为什么所有 AI 公司都在抢 coding 和办公，因为那是「在生产」的人群。做产品别被「全民可用」的叙事骗了，你的产品服务的是在生产还是消费的人，直接决定你收不收得到钱。想赚 C 端就接受低付费率，想赚 B 端就把产品做成生产工具。

**付费单元正从「企业」下探到「个人」，企业软件的老护城河在被 AI 冲垮。**
AI 办公最颠覆的一点是，掏钱的越来越是个体会为了自己的产出和位置买单的员工，而不是企业采购。过去做企业软件靠的是卖席位、锁采购流程的壁垒，现在个人自己就能为 AI 工具付费、自己选工具，采购决策链条崩了。做工具的别只盯着卖给「一家公司一套」，要能打动「一个担心被替代的个人」。谁能让他觉得这工具能保住饭碗、提升产出，谁就抓住了新的付费人群。

**轻装上阵的边缘小团队，往往比举全公司之力更能抓到 AI 窗口。**
「凡是老板盯上的产品一定死」这条规律残酷又真实。老板一关注，KPI 就上去了、动作就变形了，产品开始为迎合老板而不是为用户而做。WorkBody 赢在没人盯着、两天一更新、从 code body 这个边缘顺手做出来。这提醒所有做产品的人：别迷信资源倾斜和大厂背书，AI 时代变化按月算，能快速试错、没有历史包袱的团队反而更接近正确答案。你手里最大的优势可能是「没那么多人在乎你做什么」。

**传统互联网人的 A/B test 信仰，在没人知道正确答案的 AI 时代失效了。**
字节引以为傲的数据驱动、A/B 打一切，在 AI 面前失灵，因为这一轮没有已知的北极星指标、没有标准答案可测。评论区那句「数据驱动没了，不会做判断了」戳中本质：过去靠数据替你决策，现在数据给不了你答案，你必须靠信念和判断先选一条路。这要求做 AI 的人从「等数据说话」切换到「先有观点和信念，再用数据验证」。对习惯了凡事 A/B 的人来说，这是最需要戒掉的惯性。

**企业里最先被 AI 替代的，是上传下达的中层，不是执行层也不是老板。**
一线员工创造信息、老板做决策，真正尴尬的是靠传达信息吃饭的中层，一旦企业信息数据化、AI 能直接抓取一线数据，中层的信息差价值就没了。这个洞察对个人职业规划很有警示：如果你的价值主要建立在「知道别人不知道的信息」或「在中间传递信息」上，AI 时代你的位置最危险。要么向上成为做判断的人，要么向下成为创造一手信息的人，别停在中间做信息的搬运工。

**coding 是这一轮所有 Agent 大战的地基，办公 Agent 只是把 code 藏到了界面后面。**
表面看办公 Agent 是面向白领的自然语言产品，但它的底层还是 coding 和工具调用能力，coding as harness 是当下最头部厂商的共识。这意味着别被产品形态迷惑，决定 Agent 上限的是背后的代码能力和模型能力。对做 AI 应用的创业者，与其纠结做一个多炫酷的自然语言界面，不如想清楚你的底层有没有真本事。界面是壳，能干活的能力才是护城河，而这一轮能干活的能力全都长在 coding 上。
